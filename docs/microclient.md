# Windows 微端 Lite／Full

微端提供与浏览器版相同的核心和插件管理能力，使用独立安装包。当前接入针对官方 Windows 1.1.6；其他系统、渠道及版本是否可用，以实际提供的安装包说明为准。

## 安装与恢复

完全退出微端，将安装包解压至游戏目录外，以管理员身份运行 `install.bat`。先删除包括旧小抄在内的未知脚本并恢复官方微端；按提示确认清理，检测到残留或未确认时拒绝安装，不能通过改名或强制跳过检查。

安装器保留官方原包，恢复使用 `restore.bat`。发现未知文件时不擅自删除；必要时重新安装官方微端。安装检查不证明目录外不存在其他注入器，请自行清理外部未知脚本。

## 更新与数据

Full 与 Lite 切换保留已安装插件、配置、停用及卸载选择。支持脚本更新的接入层可在工具箱内更新，重新打开游戏生效；较旧接入层可能需要先升级安装包。

更新仅从固定可信来源读取，核对版本、大小和 SHA-256；失败保留当前可用脚本，不接受页面指定的任意地址或文件路径。清除微端用户数据可能影响插件和配置，不代表跨设备同步。

插件代码仍在游戏页面运行，摘要校验不是安全认证。与浏览器版相同，自动操作可能影响游戏资源或账号；请阅读对应插件说明及[社区插件风险政策](community-plugin-policy.md)。
