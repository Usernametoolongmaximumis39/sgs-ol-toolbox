# Windows 微端 Lite／Full

微端与浏览器版使用同一个工具箱核心和插件。请从[项目主页](https://tools.3gs.xyz/)下载对应的 Windows 安装包。适配范围包括官方 Windows 1.1.6 与 4399 渠道 1.1.3，其他版本以安装包说明为准。4399 的安装包文件已通过检查，具体功能是否可用以游戏内运行结果为准。

## 安装或切换 Full／Lite

1. 完全退出微端，包括托盘中的客户端。建议先恢复官方微端并清理以前安装的辅助脚本。
2. 将安装包解压到游戏目录之外，右键 `install.bat`，选择「以管理员身份运行」。在菜单中输入 1 安装或更新，输入 0 退出。
3. 安装器会先查找默认目录，再检查当前所在位置。如果仍无法确定，请按提示输入游戏根目录或其中的 `resources` 目录。
4. 校验通过后会直接安装。若提示可能曾用小抄或其他辅助脚本，继续安装可能使其中的脚本丢失。确认接受风险才输入 `y` 强制安装，其他输入均取消。成功后再启动游戏。

切换 Full／Lite 使用所选版本的安装包。已安装插件、配置、停用、卸载与回退状态会保留。[发行版说明](distributions.md)

## 更新和回退

在微端顶部点击「核心」，可分别检查、更新或回退工具箱核心脚本和微端底层。启动时的自动更新可以关闭，下载的更新重启后生效。下载或检查失败时继续使用当前版本。如果新版底层连续启动异常，会尝试自动回退。核心更新和插件更新各自进行。

旧安装只有重新运行适配的新安装包才能获得顶部入口和底层更新能力。浏览器脚本文件用于浏览器安装。

## 切换游戏渠道

点击微端右下角的「渠道」，登录前也能操作。也可运行游戏目录里的 `switch-channel.bat`。选择渠道后重启微端，两渠道共用本机缓存和登录状态，必要时请退出账号重新登录。旧安装可能要先运行新安装包才能看到入口。

## 恢复官方微端

完全退出微端后，以管理员身份运行 `restore.bat`，也可在 `install.bat` 菜单输入 2 卸载并恢复。恢复保留工具箱设置和插件数据。恢复检查通过后直接执行，失败时默认中止。确认接受风险才输入 `y` 强制恢复。恢复会优先使用官方备份的 `app.asar`，成功后删除被替换的 `app` 目录，其中自行添加的脚本可能丢失。其他未知脚本仍需自行清理，必要时可重装官方微端。

## 数据与风险

安装器离线执行，不上传游戏账号。微端与浏览器的数据分别保存在本机，支持的记录可通过主动绑定云同步恢复。清除用户数据可能丢失插件和设置。外部注入程序需要自行检查和清理。

工具箱插件仍在游戏页面中运行，当前没有真正的安全沙箱。自动操作可能影响道具、货币和账号。使用前请阅读对应插件说明与[社区插件风险政策](community-plugin-policy.md)。
