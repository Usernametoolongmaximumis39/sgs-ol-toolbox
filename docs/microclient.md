# Windows 微端 Lite／Full

微端提供与浏览器版相同的核心和插件管理能力，使用独立安装包。当前接入针对官方 Windows 1.1.6 与 4399 渠道 1.1.3；其他系统、渠道及版本是否可用，以实际提供的安装包说明为准。4399 渠道已通过安装包文件校验，游戏内功能是否可用以实际运行结果为准。

## 安装与恢复

0.6.79 修复微端支付宝付款码解析失败的问题。已经安装旧版的用户须完全退出微端，重新运行新版安装包；仅更新核心脚本不足以完成本次修复。保留已有插件与设置。付款仍须手动完成，请核对账号与金额，不保证折扣或到账。

完全退出微端，将安装包解压至游戏目录外，以管理员身份运行 `install.bat`。安装器会先检查默认目录；找不到唯一目录时检查当前所在目录（客户端根目录或 `resources`），仍找不到会提示输入安装路径；输入可带或不带 `resources`，支持官服和 4399。先删除包括旧小抄在内的未知脚本并恢复官方微端；校验通过后直接安装，无需输入确认。检查发现残留、文件被修改或摘要不一致时默认拒绝安装且不显示具体差异，只提示你可能以前使用过小抄或其他辅助脚本、安装可能导致这些脚本丢失；输入 `y` 即接受风险并继续安装，安装器会跳过校验并在成功后删除旧 app 目录。

安装器保留官方原包，恢复使用 `restore.bat`。恢复检查通过时直接恢复；检查未通过时默认中止且不修改文件，可按提示输入 `y` 承担风险强制恢复：优先从官方备份恢复 app.asar，并在成功后删除被替换的 app 目录。`resources` 中 app 以外的未知脚本不会被代为删除；必要时重新安装官方微端。安装检查不证明目录外不存在其他注入器，请自行清理外部未知脚本。

## 更新与数据

Full 与 Lite 切换保留已安装插件、配置、停用及卸载选择。新版可从窗口顶部的「核心」入口分别检查、更新或回退核心脚本与微端底层。启动时自动更新可关闭；已下载的更新重启后生效，建议对局结束后再重启。旧版首次使用顶部入口和底层更新时，需要退出后重新运行新版安装包。

客户端底部右侧提供“渠道”按钮，位于工具箱 UI 外部，登录前也可以使用；也可以在游戏目录运行 `switch-channel.bat`。切换只改变本机渠道配置，不替换客户端文件，重启微端后生效。两个渠道共用本机缓存和登录状态，切换后可能需要退出账号重新登录。旧版接入层需要重新运行安装包升级后才能使用此入口。

更新仅从固定来源读取并核对版本和文件完整性；下载或校验失败会保留当前版本。若新版底层连续启动异常，会尝试自动回退。清除微端用户数据可能影响插件和配置，不代表跨设备同步。

插件代码仍在游戏页面运行，摘要校验不是安全认证。与浏览器版相同，自动操作可能影响游戏资源或账号；请阅读对应插件说明及[社区插件风险政策](community-plugin-policy.md)。
