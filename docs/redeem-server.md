# 兑换码共享与隐私

兑换码共享是独立的可选功能，默认关闭。只有对应游戏成功回包被确认，且相关领取和共享设置开启时，才报告成功结果；失败、超时或未收到成功回包不报告。

报告包含成功兑换码、服务专用的账号摘要、随机浏览器安装身份及其凭据，以及工具箱运行版本信息；不发送原始账号、昵称、整段剪贴板或登录对象。摘要仍属于用于关联报告的数据，不能称为完全匿名。清除站点数据或更换浏览器会产生新安装身份，不能据此认定不同真实用户。

公共列表按有效报告处理，不是游戏官方远程核验，也不保证其他账号满足兑换条件。首次有效报告后分发期限为 5 天，后续有效报告可延长至该次成功后的至少 24 小时；过期码隐藏，再次出现有效报告时恢复相应期限。实际是否可兑换以游戏返回为准。

关闭共享、切换账号或停用插件取消待处理请求；领取账本仍按当前本地账号保存。历史未采集的数据无法补回。自动领取、共享与资源消耗的具体设置见[日常领奖](daily-rewards.md)。
