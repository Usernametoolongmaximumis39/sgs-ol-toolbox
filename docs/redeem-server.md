# 兑换码共享与隐私

在「自动 → 日常领奖 → 兑换码」可独立开关「共享」，默认关闭。只有领取和共享都开启，并收到游戏的成功确认，才会上报这次兑换。失败、超时或未确认结果不会上报。

## 共享的数据

会发送成功的单个兑换码、供服务区分账号的摘要、工具箱随机生成的安装标记和用于确认该标记的凭据，以及正在运行的工具箱版本。服务可用账号摘要关联多份报告，因此报告仍可相互关联。原始账号、昵称、整段剪贴板及游戏登录资料不会发送。更换浏览器或清除站点数据后可能生成新的安装标记。

## 兑换码可以领取多久

从首次有效报告起，普通来源通常分发 5 天，可信来源分发 7 天。维护者录入的码分发 7 天。之后收到新的成功报告时，期限可延长到该次成功后至少 24 小时。到期的码会隐藏，新报告确认后可能再次出现。实际能否兑换以游戏为准。

## 关闭共享

关闭共享、切换账号或停用插件会取消尚未处理的上报。已提交的共享结果不会随开关撤回。兑换尝试记录仍按当前本地账号保存，未采集的数据无法补回。领取和剪贴板选项见[日常领奖](daily-rewards.md)。
