# 大肥鱼卡面与鲸浪藏锋卡背

启用「卡面卡背拓展」，打开「管理 → 外观 → 卡牌外观」。「卡面」选「大肥鱼卡面」，「卡背」选「大肥鱼卡背 · 鲸浪藏锋」。可分别点预览卡选用。点「跟随游戏」恢复对应面的游戏外观。

卡面覆盖 94 张牌，包括军争常见牌、衍生装备和 42 张山河图装备。也可在游戏卡牌图鉴中查看已换图的牌。首次选用会联网加载，未覆盖的牌、部分特殊牌和加载失败的牌沿用游戏外观。外观页可重试加载。换装只在本机可见。
