# 大肥鱼卡面

大肥鱼卡面提供独立的高清卡面和卡背，安装不自动切换外观。选择时按需加载资源，未知牌名、资源缺失或失败时保留原生显示；不把相近普通牌替代特殊牌。

图片素材与程序代码许可分开。角色参考包括上善无形／溟月、ZipZipPipe／女仆鲸鱼娘及社区 Q 版形象；原设计权利归原权利人。新增编排按 CC BY-NC-SA 4.0 非商业共享，具体来源和范围以随素材提供的 ATTRIBUTION.txt 为准。图像生成工具辅助制作不消除参考素材的权利限制。

## 开发者资源要求

图集通过公开卡面接口注册，使用明确的图片尺寸、牌名映射、HTTPS 地址和 SHA-256。完整规则见[卡面与卡背](card-styles.md)、[插件 API](plugin-api.md)和[开发规范](plugin-development.md)。

大体积图片应独立托管，不把整套图片或 Base64 塞入插件脚本。托管地址需允许游戏页面无凭据跨域读取，避免登录、临时签名及不稳定的重定向；不要求使用特定服务，也不默认占用工具箱维护者的存储空间。

资源按固定版本保存；先准备并核对素材，再发布引用该资源的插件。不要用不同内容覆盖已发布的同版本图片。提供来源、作者、生成方式与实际授权，声明显示倍率及资源缺失时的回退行为。
