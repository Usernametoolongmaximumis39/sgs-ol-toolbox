# 大肥鱼卡面

大肥鱼卡面与「鲸浪藏锋」卡背可分别在工具箱「外观」中启用。卡面共覆盖 94 张牌，包括军争卡组、衍生装备和本次新增的 42 张山河图装备。可在工具箱外观页按牌名预览，也可在游戏内卡牌图鉴查看。

安装后沿用原有外观选择。选用卡面后，图片按需从 GitHub 下载，未覆盖的牌和加载失败的图片保留游戏原样。

图片素材与程序代码许可分开。角色参考包括上善无形／溟月、ZipZipPipe／女仆鲸鱼娘及社区 Q 版形象；原设计权利归原权利人。新增编排按 CC BY-NC-SA 4.0 非商业共享，具体来源和范围以随素材提供的 ATTRIBUTION.txt 为准。图像生成工具辅助制作不消除参考素材的权利限制。
