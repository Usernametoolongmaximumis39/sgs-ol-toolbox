# 日常领奖

在自动页开启后领取已满足条件的签到、邮件附件、任务、福利与活动奖励，包括斗地主和单骑连胜奖励。自动领取默认关闭，按账号保存。需要选择、购买、付费或状态不明的奖励留给手动；付费存酒不自动操作。部分活动需要先打开游戏原生页面以准备数据。

未设置时默认排除免费招募令、抵价券与体验卡，已有选择保持不变；邮件可单独排除，免费翻翻默认关闭。斗地主和单骑兑换使用独立配置，可能消耗欢乐豆，开启前核对项目和限额。关闭总开关停止等待及后续请求，已发送请求无法撤回；结果不明时先在游戏中核对，不自动当作失败重试。

兑换码支持读取服务、剪贴板导入与成功码共享。剪贴板和共享默认关闭。开启剪贴板后仅在游戏页面可见且获得焦点时检查；按行识别口令，跳过无效行并显示批次进度。共享只上传游戏明确成功的码与账号摘要，不上传失败码；详见[兑换码共享与隐私](redeem-server.md)。需要联网访问兑换码服务，第三方处理、保留期限及同意方式以该说明为准。

本地演练不代表所有官服活动均已实际到账，领取结果以游戏为准。
