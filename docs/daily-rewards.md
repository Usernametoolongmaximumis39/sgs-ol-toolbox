# 日常领奖

入口：自动 → 日常领奖。需要核心0.5.0或更新版本，并刷新游戏页；旧核心不认识本版所需免费招募/礼包配置表。独立包 ID 为 `daily-rewards`，仅依赖工具箱核心 API；不依赖卡牌、特效屏蔽、皮肤收集或旧小抄。源码只导入本插件目录。

- 签到：已签到天数的普通奖励、已满足 VIP / 官阶条件的额外奖励、累计签到奖励。不会调用补签、购买或充值接口。
- 邮件：系统及好友邮件的道具附件和礼包附件。生日邮件、未知附件，以及原生回包会自动删除的 `opt=sys` 邮件留给用户处理。读取未读邮件时先调用原生ReadMail并等待对应读信成功，之后再请求附件；插件不调用删除接口。
- 任务：游戏已接收、已完成、可领取的普通任务奖励，以及排位每日首胜和三胜奖励。新增第二个原生任务经理中的活动登录／在线奖励；纯被动条件的重复任务每次只领一份，以已完成次数区分。累计消耗银两的已完成统计任务可领取；需要选择奖励、购买、兑换、领取时消耗、重复多次、过期、前置未完成与原版已排除的特殊任务不自动领取。不会自动接受尚未进入服务器记录的任务。

- 福利：砍树启用、免费道具兑换及领取，公会剩余免费敲鼓，已激活周/月卡及新权益卡奖励、每日银两；首充资格满足且原生明确免费的单抽祈福，无资格跳过；商城免费礼盒按原生零价、开放时间、限购及已领状态判断。
- 活动：节日和累计登录、军典/节钺令/同乐乐、新福利军令、官阶日周、武将集册集灯、免费武将包、排位奖励、邀请助力币、低保豆、酒馆已完成任务。
- 兑换码：提供领取、读取剪贴板、共享三个开关。服务器每次打开游戏最多检查一次；剪贴板默认关闭，开启后在游戏页面可见且有焦点时自动检测，内容变化或解析版本升级时导入未尝试的新码。支持每行一个4–8字中文口令，可混少量英文数字，兼容“力争32强”；状态及混杂说明整段拒绝。共享默认关闭；新公网桥接只上报游戏明确成功的单个码，原本机模式仍使用人工白名单。按账号永久记录已发送的码，详见[兑换码服务说明](兑换码服务.md)。

需要选择具体武将/奖励、购买激活和付费抽取仍留给手动。部分活动须先打开游戏原生页面使数据就绪。免费礼盒使用已存在的道具列表或已打开特惠界面的原生条目，不创建窗口；数据未就绪时暂缓。

自动领取默认关闭，开关按当前账号保存。打开后自动检查普通奖励，每分钟检查一次；没有手动领取或停止按钮，关闭总开关即可终止等待和后续请求。采用点击卡片选择排除项的方式，显示免费招募令、抵价券、体验卡、欢乐豆、邮件、免费翻翻六张卡片。卡片固定为2列3行，点击后灰暗并划线，再点一次恢复；总开关为滑动样式，兑换码三项为小按钮，均无普通复选框。免费招募令同时控制原版对应的每日免费武将包入口。邮件恢复独立开关，默认开启；免费翻翻默认关闭，开启后仅在五张卡中已有至少一张翻开且仍有空卡、首充和活动免费资格均满足时，发送单张零费用请求。五张全空不开始，不复位，不“全部翻开”。升级保留账号原设置和兑换码／剪贴板设置。

含有排除物品的整份奖励跳过，不拆分领取。任务、签到、排位、军令等读取已知奖励明细及物品配置，发送前再检查；欢乐豆排除同时阻止免费低保豆、同乐乐整包、官阶每日入口。邮件ITEM附件使用真实id/ctn数组，GIFT附件从gn_dbs_giftbag解析礼包内容；确实无法读取完整奖励明细的邮件、福利或活动整包，在任一排除开启时暂缓领取，避免误领；未知明细不会当作空奖励。免费祈福、免费招募、可选免费翻翻属于明确授权的免费抽取，按各自免费资格执行，不用未知随机产出套用物品排除。取消排除后可继续检查，跳过项不会写入已发送账本。

执行时按现有管理器按需加载官方配置；福利准备会有界刷新树和卡状态。安装及打开领奖面板本身不下载配置。

服务器列表有变化时下载文本后在本地筛选新增码；未变化时新服务返回HTTP304，不重复下载正文。一次检查失败也不会在本次游戏内重试，避免频繁请求；旧服务没有ETag时仍遵守一次GET限制。剪贴板上次内容以SHA-256摘要按账号保存，重载后同样跳过不变内容，不额外保存完整剪贴板原文。

领取前保存本账号、本服务器日期的请求标记。只有游戏对应状态变化或能关联该请求的明确成功回包才计入成功；函数返回或无关回包不算成功。明确失败保留失败记录并继续后续项目，未确认只阻塞其所属工作流（例如同一天签到的后续步骤、同轮翻牌），其他独立奖励继续。

单次请求最多等待 8 秒，未确认则保留已发送记录并跳过同组后续，其他独立领奖继续；同日重新执行、热重载或刷新都不会自动重发该请求；兑换码的已发送标记跨天保留。待游戏状态更新后可重新检查。一次最多处理 200 项，兑换码最多 100 个不同值，输入超过 16000 字符整体不执行兑换。界面保留运行状态与设置，不展示待选奖励、领取详情或兑换码历史。去重账本继续保存，不能当日志删除。树流程同一账号同日确认领奖后不重新启用。停用、卸载、关闭自动或账号/日期变化时终止等待及后续请求，无法撤回已经发送的请求。

运行时管理器、服务器日期、任务数据等未就绪时显示原因。邮箱列表取现有数据，必要时先打开一次原生邮箱。缺少额外签到配置时普通签到仍可处理，额外和累计奖励提示稍后重试。

自动领取默认关闭；未设置时默认排除免费招募令、抵价券与体验卡，已有显式设置优先。兑换码直连 `https://redeem.3gs.xyz`，剪贴板和共享默认关闭；共享只上报游戏明确成功的单个码与账号摘要，详见 [兑换码共享与隐私](redeem-server.md)。

发财树归入总开关流程，按资格执行启用、免费兑换、砍树和领奖，不操作需要付费的存酒。已领状态用于避免重复；砍树完成后刷新每日红点不表示其他奖励均已领取。需要选择、付费、激活或数据未知的项目保留手动。

斗地主／单骑自动兑换按独立配置执行，可能消耗欢乐豆；开启前核对兑换项目、库存和限额，不将有费用的兑换当作免费领取。完整到账和跨日行为仍需按实际游戏结果核对。
