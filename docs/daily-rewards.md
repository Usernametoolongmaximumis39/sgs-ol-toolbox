# 日常领奖

打开工具箱「自动 → 日常领奖」，登录后可开启「自动领取」。总开关默认关闭，按账号保存。开启后会领取符合条件的签到、邮件附件、任务、福利和活动奖励，也包括斗地主和单骑连胜奖励。部分活动需要先打开游戏自己的活动页。回归、回流及老玩家任务和付费存酒留给你在游戏中处理。

## 奖励和排除项

- 「免费招募令」「抵价券」「体验卡」「欢乐豆」「邮件」「免费翻翻」可点按切换「领取／跳过」。免费招募令、抵价券和体验卡默认排除，欢乐豆奖励与邮件可单独跳过。混合奖励中有被排除的物品时，整份奖励会跳过。
- 「免费翻翻」默认关闭。打开后只续翻你已开始的一轮里可免费翻的一张，五张都未翻时会等你开始。
- 免费礼盒只在游戏确认活动有效、尚有领取次数且价格为零时领取。需要手动选择或状态不明的奖励请在游戏中核对，待核对列表会显示项目。
- 发财树符合首充和余额条件时可能购买砍树道具，每次最多消耗 200 元宝。遇到特殊事件需自己处理。结果不明时先查看游戏记录。

## 欢乐豆商店

在游戏的斗地主或单骑兑换商店，点商品旁的「自动」加入自动兑换，再点「已选」取消。选中后会先倒计时 5 秒，期间取消可阻止尚未提交的兑换。只对有周期限额的商品提供自动兑换，余额不足时只兑换买得起的数量。开启自动兑换可能扣欢乐豆，选前先核对价格和限额。关掉「自动领取」会暂停商店自动兑换，保留所选商品。已发送的购买或领取无法撤回。

## 兑换码

这三个开关独立于「自动领取」，关闭总开关后按各自设置运行。

- 「领取」默认开启，获取可用兑换码并尝试尚未尝试过的码。需要联网访问兑换码服务。
- 「剪贴板」默认关闭。打开后只在游戏页面可见且有焦点时读取剪贴板。可识别完整序列号和 4–8 字的中文短口令，可夹带少量英文数字。每行一个，无效行会跳过，也可写成「兑换码：口令」帮助识别。
- 「共享」默认关闭。打开后才会把游戏已确认成功的单个码及用于关联的资料发给共享服务。它会处理哪些数据、保留多久，见[兑换码共享与隐私](redeem-server.md)。

所有奖励是否到账以游戏为准。
