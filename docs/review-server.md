# 自动投稿材料与反馈

通过 GitHub PR 投稿，无需提交服务器凭据。审核服务已启用；客户端分级市场仍待接入，不能把现有普通市场视为已经完成试用区及风险确认。

## 启用自动投稿

在 PR 正文加入 `<!-- sgs-review:submit -->`，复制[元数据示例](../examples/plugin-template/review-submission.example.json)为仓库根目录 `review-submission.json`，与插件源码、测试、Markdown 说明和素材授权一同提交。一个 PR 处理一个插件，不冒用现有稳定 ID。

| 字段 | 含义 |
| --- | --- |
| `pluginId` | 与插件清单及目录相同的稳定 ID |
| `authorName` | 自填作者显示名，1–80 字符；GitHub 数字 ID 由服务取得，不能自报替代 |
| `providerConsent` | 同意处理投稿材料的第三方列表；自动投稿须包含 `bigmodel`（智谱），仅在也接受 DeepSeek 处理时加入 `deepseek` |
| `allowLimitedModeration` | 是否接受政策范围内的有限内容调整，默认 `false`；目前记录授权，自动调整功能未完成 |
| `riskDisclosure` | 必填对象，见下表 |

| 风险字段 | 填写内容 |
| --- | --- |
| `dataRead` | 读取的数据 |
| `network` | 联网目标与发送字段 |
| `automation` | 自动游戏操作与触发条件 |
| `resourceUse` | 道具、货币等消耗及条件 |
| `license` | 代码许可证及素材来源、授权 |

各风险字段为 1–2000 字符，无则填无。元数据不加入插件 manifest。请勿提交密码、密钥、登录对象、真实账号日志或无关私有源码。材料与最终包会发送至明确同意的第三方进行审核；首选处理明确失败且作者同意备选时才使用 DeepSeek。不同意第三方处理可请求人工处理。

## 当前接收范围

自动路径接收本插件目录、相应测试与文档及必要登记修改；涉及核心、共享代码、依赖或工作流的变更需人工处理。缺少材料、不支持的资源类型、体积过大或无法完整读取的投稿会要求补充或转人工，不截断后放行。

作者可以查看接收、审核、试用上架、人工结论及延期反馈。机器首次反馈目标 5 分钟，人工处理目标为初审通过后 24 小时；超时保持原状态，不自动通过。通过初审后自动进入试用范围，人工通过后移除试用标签。实际客户端入口的可用性以功能上线状态为准。

新版本重新审核，用户取消风险升级时保留现有可用版本。账号身份、哈希、调整授权和审核状态的含义见[社区插件政策](community-plugin-policy.md)。
