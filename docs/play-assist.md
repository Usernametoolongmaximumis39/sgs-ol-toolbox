# 出牌辅助

可长按技能开启辅助，点按取消；山河长按约半秒，其他模式约两秒。右键长按可记住单个技能，移动端继续按至约三秒或五秒也可记住。长按辅助默认开启，已有明确设置优先；其余自动确定与询问跳过按独立设置执行。开启的辅助可能代为选择或确认游戏操作，请先核对设置；停用插件停止后续处理。

「牌局 → 出牌辅助 → 裴秀辅助」默认开启。绘图时显示可行走法；采风时点花色可批选，右键或长按花色可反选，右键或长按卡牌可锁定。锁定只影响快捷选牌，仍由玩家手动确认。

## 开发历史

- 0.2.38：加入裴秀的绘图和采风提示，补充天书、权御和魔张飞的辅助提示。三国斗地主牌桌不启用出牌辅助。

- 0.2.19（2026-11-19） 修复单骑场景误触发自动跳过无懈的问题。已开启该选项时，仅在山河图战斗中自动跳过相应询问。

- 0.2.16（2026-11-17）：补充强识摸牌与武娘取牌辅助，武娘优先选择可选防具、其他装备，再选择手牌；狂骨按当前体力选择回血或摸牌。仍需开启相应技能辅助，强识前半段选人和展示保留手动。

- 0.2.12（2026-11-16）：长按技能辅助默认开启，保留已有设置；右键长按可记住技能，移动端继续长按也可记住，点按取消。移除统一跨局记忆开关，改为逐技能记忆，并修正部分询问处理。
