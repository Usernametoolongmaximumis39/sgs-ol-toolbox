# 出牌辅助

独立插件 `play-assist`。入口「牌局 → 出牌辅助」，仅依赖核心，设置和跨局技能记忆保存在本机。未设置时长按技能辅助默认开启，其余选项默认关闭；已有显式设置优先。

支持的原生技能在山河图长按0.5秒、其他及未知模式长按2秒启用辅助；未到时松开或移出不会锁定，点击解除。面板状态按钮支持键盘操作；跨局记忆默认关闭。支持技能和精确版本ID可在折叠区查看，同名技能不自动扩展支持。

自动确定、自动火攻、跳过无懈、跳过他人求桃、跳过应变助战和技能连按分别设置。多张选牌、未知目标及专门要求手动的分支不自动提交；连按仅解除本地节流，不绕过服务器规则。折叠只隐藏界面，停用释放包装并恢复原生行为。

迁附3750／3753按原生过滤选择一张可用牌：阳用黑牌作过河拆桥，阴用红牌作火攻；目标手动选择。锁定时取消迁附控顶及驭势询问；取消入口不可用时保持手动。火攻后续仍由独立开关控制。驭势3751不作为自动发动技能。

龙吟仅在本人回合、本人使用且明确为红色的杀时辅助；支持有公开素材与杀身份依据的转化杀。黑色、混色、未知来源保持手动。怀远及其他选自己策略仅在原生目标可选时操作，不覆盖已选其他目标。

独立开关默认关闭。新版权道3184按钮显示“杀数量/普通锦囊数量”，杀含属性杀，普通锦囊不含延迟锦囊；空手牌显示0/0，资料缺失恢复原文。仅改变显示，不选牌或发动技能；旧版权道3140不处理。

未知场景、回放、观战、死亡、托管与已结束牌局不据此自动操作。技能策略与真实客户端完整交互尚未全部完成官服验证。
