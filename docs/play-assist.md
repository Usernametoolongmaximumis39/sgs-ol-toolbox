# 出牌辅助

打开工具箱「牌局 → 出牌辅助」，可为支持的技能省去部分重复操作，也可只用武将提示。开启自动功能前，请先核对每项会代为选择或确认什么。

## 长按与记住技能

- 「长按技能辅助」默认开启。山河局按住技能约半秒，其他支持的模式约两秒，开启本局辅助。点一下已开启的技能可取消。
- 鼠标右键长按可记住该技能，移动端继续按到山河约三秒、其他模式约五秒也可记住。逐个技能保存，点已记住的技能可取消。
- 在「当前可辅助技能」可直接点技能名切换本局辅助，卡片会显示未开启、本局开启或已记住。展开「支持技能」和其中的「版本详情」查看技能范围。同名技能的不同玩法可能有不同支持情况。
- 强识只辅助确认摸牌，选人和展示手牌需手动。鬼才、鬼道只在同时拥有洛神或界洛神等所列条件时辅助。

## 自动操作开关

| 开关 | 作用 |
| --- | --- |
| 选好后自动确定 | 对识别到的已完成选择代点确定 |
| 自动火攻 | 在支持的火攻询问中代选展示牌或弃牌 |
| 跳过无懈 | 仅在山河图跳过自己回合第一轮无懈询问 |
| 跳过他人求桃 | 跳过支持的他人求桃询问 |
| 跳过应变助战 | 跳过支持的应变助战询问 |
| 技能连按 | 去掉支持的技能连续按键间隔 |

以上自动操作开关默认关闭。遇到未识别、条件不足或需要你决定的选项时，请查看游戏提示。

## 武将辅助

- 「权道数量」显示能确认的权道数量。「天书辅助」为南华老仙的天书选择和已写入效果补充说明。
- 「权御辅助」显示魔孙权六种权御效果及其记录。选择期间可继续查看标记；支持时悬停可看效果说明，也可在等待自己操作且游戏允许时点标记打开权御记录。白虹加伤害、青冥加目标、辟邪无视防具、紫电不可响应、百里额外结算、流星不限使用次数。
- 「魔张飞辅助」在魔张飞自己的回合显示其他角色的焯魂体力分界。勾号表示本回合已观察到相应的颜色变化，问号表示记录有缺失。
- 「裴秀辅助」在绘图时显示可行路线，窄屏可滚动。采风时单击花色按钮选择或取消该花色，可叠加多个花色。右键、长按或 Shift+Enter 可选其余花色。右键或长按卡牌可锁定它，快捷选牌不会改动锁定牌。采风最后由你用游戏按钮确认。

武将提示默认开启。观战、回放、阵亡、托管等情况下自动操作会受限。此插件不在三国斗地主牌桌执行出牌辅助。
