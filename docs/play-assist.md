# 出牌辅助

独立插件 `play-assist`，首版 0.1.0，入口「牌局 → 出牌辅助」。仅依赖核心 API，所有业务开关首次安装均关闭。核心统一提供插件标题、图标和折叠；折叠不会停止辅助，停用插件会释放原生监听与包装。

开启「长按自动发动」后，在支持的原生技能上长按启用自动发动：山河图 0.5 秒，其他模式 2 秒，未到时松开或移出按钮不会锁定，点击解除。当前技能也可通过面板中的状态按钮切换，支持键盘。开启「跨局记忆」保存本机技能选择；默认不记忆。技能实际名称使用客户端数据，不把不同 ID 的同名技能合并。

其他选项彼此独立：选好牌与目标后自动确定、自动火攻、跳过无懈、跳过他人求桃、跳过应变助战、技能连按。自动确定保留旧版手气卡、更换手牌、连环、业炎等排除场景，不自动替用户选择普通目标。选牌上限超过一张时沿用旧版手动确认，避免用户尚未选完便提交。技能连按仅解除本地按钮节流，不绕过服务端规则。
