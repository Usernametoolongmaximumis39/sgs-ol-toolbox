# 盖主速刷

先安装并启用「百胜战功」，再到工具箱「自动 → 盖主速刷」。适合两个已约好的账号刷盖主，也可以按模式挂机。选择方式后由你主动开始。

## 双账号速刷

- 开房端选「盖主小号」。在大厅点「创建盖主房」，面板显示房号和密码，可点「复制密码」并手动邀请同伴。同伴在大号一端选「反贼大号」，加入并坐好后，小号端点「确认并开始速刷」。
- 已在可用房间时可点「开始速刷」。出现「强制开始」时会采用当前房间设置，先核对房间和同伴。等待同伴时可点「取消速刷」，运行中可点「停止速刷」停止本端后续操作。
- 「等1分钟」调整小号开始苦肉的等待方式，开启后等到剩 3 秒或已等待 45 秒。小号可能自动补普通小杀并点将黄盖。

## 自动挂机

- 选「自动挂机」，然后选择「身份」「国战」或「单骑」。点「开始挂机」运行，点「停止挂机」停止本端。
- 支持的模式可在「点将 · 百胜轮换」选「不点将」「随机点将」「按序点将」。随机或按序会从可用的百胜目标尝试点将；需要消耗点将卡等资源时请先确认是否愿意启用。
- 「手动停止」等你点击停止。「酒馆三项领齐」确认三项均已领取后打完本局停止。「定时」从启动时计时，填入大于零的小时数，到点后打完本局停止。
- 面板会显示当前武将、完成局数和进度；遇到异常可展开错误详情和运行记录。

自动操作会代为选将、出牌、续局等，单骑商店操作可能消耗局内货币。房间状态、资格与战功结果以游戏为准。
