# 盖主速刷

需要先安装百胜战功插件。两个账号手动进入同一自建身份房，小号作为房主和主公，大号作为反贼，各自选择角色后手动开始。盖主端检查房间设置、选择黄盖并执行对应流程，反贼端可按百胜进度选将和托管。

点将可能消耗点将卡等游戏道具。启动前确认房间规则、身份、人员与资源；插件不创建房间，不登录或控制另一账号。停止、切号或停用会停止后续操作，刷新、重载或升级不会自动开始。不要同时运行其他挂机或速刷脚本。

房主端只在手动开始后的首次等待房间检查规则。有效房间密码会保留，必要时生成四位密码并在面板显示，请妥善保管。自动修正失败时，速刷会停止并提示检查房间密码、身份选择和点将权限，并关闭手牌构筑。密码需为 1–4 位数字，且不能只填 `1`。

确认房间规则后，等待 3 秒即可点击「强制开始」。本次启动会沿用当前房间规则，仍要求当前账号是身份演武房主。房间规则可能影响选将和开局。等一分钟使用近似节奏，完整流程仍需在官服核对。

也支持反贼大号作为房主进行单人百胜，或进入单骑人机训练；启动前核对模式和资源。单骑训练自动选购可能消耗局内货币，取消无懈默认开启，可在面板调整。
