# 盖主速刷

先安装百胜战功。在面板选择盖主小号、反贼大号或自动挂机，再手动开始。盖主可以在大厅创建带密码的身份演武房，房号和密码会显示在面板。首局先确认已入座的同伴，同伴离席时暂停。

自动挂机支持身份、国战和单骑。可手动停止、定时停止，或在酒馆三项奖励已领取后停止。单人补小杀会尝试重补，多次失败后提示剩余座位。切号、停用和重载会结束当前运行。

点将可能消耗游戏道具，单骑自动选购可能消耗局内货币。开启前核对房间规则、同伴、模式和资源。酒馆奖励请在游戏中领取。官服端到端流程仍待复验。
