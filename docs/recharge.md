# 旧周月卡

在工具页查看旧周卡、旧月卡状态。未激活且能确认商品报价时，可核对信息并打开游戏直购。到期提醒默认关闭，可在插件中开启，奖励领取由日常领奖处理。

付款由用户手动确认。旧卡可能停售，激活、奖励和退款以游戏实际结果为准。结果不明时请先核对游戏状态。

## 开发历史

- 旧周月卡 0.1.16（2026-11-19）：精简旧周卡和旧月卡的查询、到期提醒与直购入口。打开游戏直购前仍需核对商品，付款由用户手动确认。


- recharge 0.1.13（2026-11-17）：将95折开关移到游戏充值按钮左侧，新增自定义元宝输入并修复入口定位和付款码显示。仍默认关闭；创建订单会向官方支付服务发送账号及订单信息，需核对账号、数量和风险后确认，付款须手动完成，不保证折扣或到账。


- 0.1.7（2026-11-16）：修复微端支付宝正常付款二维码区域空白的问题，保留备用跳转码和收银台入口。出码仍需核对账号与金额并确认，付款须手动完成，出码不代表付款或到账。

- 0.1.6（2026-11-16）：统一充值与旧卡界面的提示和操作外观，保留每次订单的账号核对与风险确认。付款仍须人工操作，不保证折扣、到账或旧卡激活。
