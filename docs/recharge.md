# 95折充值与旧周月卡

入口：工具 → 95折充值与旧卡。独立插件 `recharge` 0.1.1，随核心 0.5.113 提供，也可从本地市场单独安装。

充值沿用自有拓展 2.6.8 的官方 `https://ol-payment.sanguosha.com/v1/{wechat|alipay}/qrcode/order/create`、channel=210000、server_id=1100 与 MD5 签名协议。向该官方域名发送登录账号、玩家ID、昵称、元宝数、时间戳及可读取的设备ID，不发送密码。登录名读取 LastUserName / SGS_LASTLOGIN_ACCOUNT / SGS_LASTLOGIN_ACCOUNT1，玩家ID读取核心当前账号 ClientId；自动读取后仍需人工核对。表单与订单不持久保存。

用户先选择支付方式，再核对账号、玩家ID和元宝数并确认风险，才创建一次订单。微信展示返回的图片，支付宝展示收银台链接二维码和打开收银台链接。支付宝二维码可能需要在收银台继续操作。收银台只接受 HTTPS 的 alipay.com / sanguosha.com 及其子域，不执行回包HTML。未查询付款状态；出码、打开收银台均不表示扣款或到账成功。修改表单或账号切换清除旧结果，关闭面板或停用取消进行中的请求，无自动重试。

95折、充值活动计入与最终金额以官方收银台和游戏为准；本地移植不证明历史通道仍有效。界面常驻提示渠道失效、给他人充值、不到账、退款等风险，建议先小额验证。

## 旧周月卡

旧小抄购买路径在 `sgs-cards-reference-decoded.js` 的 VN 函数中核对：旧周卡 12981201，payType=1，priceNum=1200；旧月卡 12981501，payType=1，priceNum=2800。报价字段不能擅自当作元宝或人民币单位，最终币种金额以游戏收银台为准。

分别等待 ServerProxy 的 ClientPrivilegeInfoRep / ClientPrivilegeDataRep，调用已有 WelfareManger 的 SendClientPrivilegeInfoReq / SendClientPrivilegeDataReq；要求 data.code=0、商品ID／payType／priceNum完全匹配、当前卡明确未激活。未知状态或已激活阻止购买。确认风险后再次刷新报价与状态，再从 ClientDirectPurchaseRep 的既有 caller 恢复原生直购管理器，调用 WebDirectReq(goodsId,1)。不依赖小抄全局，不创建新的原生管理器。

每次面板挂载对同账号同卡仅打开一次直购，结果不明先核对游戏，重新打开面板才可重新操作。此入口保留旧卡购买功能及周／月卡独立到期提醒开关（默认关闭，保存插件设置）；提醒依据官方明确的 bActive 状态，未知不当作到期。启用提醒时查询一次，后续观察原生卡数据更新，每次到期状态只提醒一次，不自动购买。旧卡奖励领取继续由独立日常领奖插件负责。

旧卡可能停售、激活失败、没有奖励或无法退款，风险与确认文案常驻旧卡入口。工具不保证补偿；不会绕过服务器商品与到期校验。

## 非官服渠道

95折仅限 web.sanguosha.com；非官服和本地演练域名均禁用账号／金额表单与微信／支付宝出码按钮，常驻显示“95折充值已禁用”。请求前再次检查渠道；旧周卡／旧月卡购买与提醒不受该官服域名限制，仍按游戏实时商品报价和账号状态校验。购买操作结束后也不会重新启用95折控件。Chrome 模拟非官服验证旧月卡直购参数正确且充值请求为零，截图 non-official-280.png。

## 0.1.2：4399内嵌页面识别修正

旧版只看当前游戏框架域名，会把4399外层内嵌的官方资源页误认作官服。现在检查顶层页面与祖先来源，跨域顶层无法读取或来源为渠道页时禁用95折，兼顾入口client参数。非官服充值区域仅显示“当前服务器不是官服，95折充值已被禁用”，隐藏整段充值说明、表单、金额与出码按钮，保留旧卡购买及其风险提示。Chrome使用 game.4399iw2.com 外层嵌入 web.sanguosha.com 的真实跨域iframe模拟验证，确认充值界面隐藏、支付请求为零、旧月卡原生直购仍可达；尚未在真实4399账号页面验收。核心0.5.114／插件0.1.2。

## 0.1.3：付款码位置与支付宝最终码

确认区、状态及付款码统一移至旧周月卡上方。支付宝返回 qr.alipay.com 直接链接时本地生成最终码；返回收银台地址时恢复旧拓展的沙箱iframe裁切显示（170px码、左8／上4偏移，按面板宽度缩放，保留白边）。默认不再展示冗长的收银台跳转码，备用跳转码折叠在详情中。无法加载嵌入收银台时使用打开收银台链接。ResizeObserver及iframe随修改表单、账号切换、面板销毁与停用清理。

浏览器以模拟收银台页面验证最终码裁切、248／280／420px布局、付款码在周月卡前及账号切换清理；该截图不证明真实支付宝收银台当前布局或嵌入策略，仍需实页复测。核心0.5.116／插件0.1.3。

## 0.1.4：界面整理与每次登录风险提醒

删除200快捷档位（仍保留自定义数量），金额改为四列且用金色底光及 aria-pressed 标记当前档位。支付说明默认折叠，重新读取账号为次要操作；核对订单按金额、支付方式、账号、玩家ID、昵称分行，主操作与取消分级。

充值及旧卡风险合并成首次提示，点击“我已了解，本次登录不再提醒”后本次登录隐藏。提示状态仅驻留当前游戏页面，跨面板重建、插件重载保留；观察到账号为空或切换时重置，刷新游戏页面也重新提醒。不持久保存风险确认，不省略每笔订单核对，也不改变非官服95折禁用。

Chrome模拟回归覆盖200档位移除、确认后面板重建不重复提醒、账号变化重新显示、浅深主题和248／280／420px。未真实付款。核心0.5.117／插件0.1.4。
