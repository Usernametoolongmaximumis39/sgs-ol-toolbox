# 旧周月卡

登录游戏大厅后，打开工具箱「工具 → 旧周月卡」。可查询旧卡状态、开启到期提醒，或在游戏仍提供该商品时打开直购。

- 点「旧周卡」或「旧月卡」查询游戏状态。若可购买，会显示报价，请核对卡种和账号。
- 两个「到期提醒」可分别开启，默认关闭。游戏返回状态后，会显示有效、已到期／未开通或状态未知，并在能确认到期或未开通时提醒。
- 「确认并继续」会再次核对商品，然后打开游戏直购入口。「取消」可放弃。进入游戏收银台还要自己确认付款，实际币种和金额以收银台为准。
- 「我已了解，本次登录不再提醒」只隐藏本次登录的风险提示。

旧卡可能停售，购买也可能无法激活、没有奖励或无法退款。打开直购入口后先在游戏中核对订单、扣款和卡状态，确认结果后再决定是否重试。
