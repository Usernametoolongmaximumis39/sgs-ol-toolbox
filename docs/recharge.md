# 95折充值与旧卡

在工具页选择支付方式，核对登录账号、玩家身份与元宝数，并确认风险后生成一次付款码或打开官方收银台。创建订单会将账号、玩家身份、昵称、元宝数、时间及可读取的设备信息发送给官方支付服务，不发送密码。表单与订单不长期保存，切号或修改表单会清除旧结果。

付款须人工完成；出码或打开收银台不代表已扣款、到账或享受折扣。折扣、活动计入和最终金额以官方收银台及游戏为准，渠道可能失效，存在给错账号充值、不到账和退款困难等风险。仅在可确认的官服页面开放充值，来源无法确认时禁用。

旧周卡、旧月卡需先确认当前商品报价和未激活状态，再由用户确认打开原生购买。状态未知或已激活时阻止购买；结果不明时先核对游戏。旧卡可能停售、激活失败、无奖励或无法退款，工具不保证补偿。到期提醒默认关闭，开启后按游戏明确状态提醒，不自动购买。旧卡奖励领取由日常领奖插件处理。尚未验证真实付款、到账、折扣及旧卡激活。
