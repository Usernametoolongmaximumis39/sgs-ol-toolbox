# 好友与聊天

在原生好友列表提供置顶，在聊天中补充官阶／人机标记和可点击的短房号；按账号保存好友稳定身份、改名记录与导出数据，不上传本机记录。

- 仅正式好友可置顶，置顶组和普通组各自保留原生排序。以稳定用户码关联好友，资料缺失时先等待，不用列表槽位猜测身份。取消置顶、停用或切号恢复原生显示。
- 首次完整资料建立基线，发现改名后保存并提示；写入失败保留原基线与完整错误。刷新不重复提示已记录的变化。支持 JSON 导出，卸载不自动删除本机记录。
- 原生可点击用户名保留链接并补充可取得的官阶。按当前可见聊天区域补查资料，滚动后查询新露出的昵称；保留原生请求节奏与同昵称冷却，不强制刷新。未知官阶不猜测；人机标记采用账号范围启发式。
- 完整的1–5位正数房号可作为进房候选，每条普通发言最多8个。点击按当前模式和分组加入；模式未知时等待。进行中或状态未知的牌局须先通过游戏原生流程退出。密码房使用原生密码输入窗口，超时保留结果未知。

首次完整查询建立永久拥有武将的基线，之后完整结果有新增才提示；限时试用、减少或未收齐的数据不算新增。使用游戏原有查询与缓存，每名好友约11分钟复查，不读取购买记录，不能证明付费。

提醒位于游戏画布顶部，可逐条关闭，长内容可滚动，没有自动消失计时。刷新、切号或停用清除当前页面弹窗；已保存基线避免重复提醒。资料和基线仅存本机。

好友、置顶及改名记录按账号隔离；缺少身份、昵称或完整结果时等待。关闭面板不停止插件，停用释放查询、包装与自有资源。HUD 保留改名历史、导出、登录等待与存储错误，不展示内部聊天诊断。

真实协议时序、服务端查询结果和完整牌局行为尚需官服复核。
