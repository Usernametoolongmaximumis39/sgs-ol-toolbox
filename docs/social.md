# 好友与聊天

在游戏好友菜单中置顶好友、查看昵称变更；公屏中的房号可用于进房，聊天可补充官阶。置顶好友的将灯变化会提醒，可导出当前账号的好友与已拥有武将记录。首次查询只建立基准，后续约每十一分钟复查；将灯变化不能判断是否付费。关闭提醒或停用插件可停止后续检查，账号记录保存在本机。

「工具 → 好友与聊天」可关闭绑定码过滤。过滤只影响你看到的综合聊天、系统消息和高级诏令，不会删除其他玩家的消息。

- 0.1.25：改进绑定码过滤，优先补全当前可见消息的官阶，同一条消息里的多个官阶一起显示。

- 好友与聊天 0.1.17（2026-11-19）：大厅房间列表新增「只显示无密码房」，并调整公屏房号识别与进房入口。


- social 0.1.14（2026-11-17）：优化好友将灯变化横幅，补充好友消失提示；本机主动删除成功后清除对应本地记录，好友消失不能判断由哪一方删除。首次读取仍只建立基准。


- 0.1.12（2026-11-16）：新增置顶好友将灯变化提醒与已拥有武将记录，可导出当前账号记录；聊天官阶查询和好友界面显示更清晰。将灯变化不代表付费判断，首次读取仅建立基准。
