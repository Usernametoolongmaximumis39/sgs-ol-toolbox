# 好友与聊天

在游戏里快速找房、整理公屏、关注好友的昵称和武将变化。到工具箱「工具 → 好友与聊天」设置聊天过滤、本地气泡和表情，或查看并导出好友记录。

## 聊天与找房

- 公屏中识别出的房号可以点击进房。已经在牌局里时，先通过游戏退出本局。聊天消息会补充游戏能查到的官阶。
- 大厅房间列表的「只显示无密码房」会筛去有密码的房间，再点一次恢复显示。
- 「过滤绑定码」默认打开，控制综合、系统消息和各频道高级诏令里的相关内容。它会过滤含「互」「绑」「好友」「周年」的相关消息，以及以 A 或 C 开头、至少五位连续大写字母的疑似绑定码。过滤只影响自己看到的内容。

## 好友变化

- 在游戏好友菜单点「置顶好友」或「取消置顶」。登录后陆续查询置顶好友，同一次登录中每位好友至少间隔一小时。首次读取作为比较基准。
- 新增永久拥有武将时会在游戏上方提醒，点叉关闭。将灯变化无法判断武将获取方式。好友消失也无法判断由哪一方删除。
- 「导出好友记录」下载当前账号的好友、昵称变化及已保存的拥有武将名单。取消置顶会停止该好友的自动检查，已保存的名单仍可导出。最多保留最近 200 条昵称变化。

## 本地气泡与表情

- 「本地聊天泡泡」默认开启。打开后，点「打开个性化」进入游戏「个性化 → 对话气泡」挑款式。也可点「导入图片」，再点「用自定义」使用静态图片。「恢复游戏气泡」切回游戏样式，关闭开关也会恢复游戏显示。
- 「表情预览与解锁」打开游戏表情页。选中可预览的表情后点「加入本地」。点列表里的表情可在牌桌上播放，点旁边的移除按钮可从列表删除。刷新游戏会清空这组表情。解锁由你在游戏中操作，请核对可能消耗的道具。

好友与将灯检查会向游戏查询资料。好友记录按账号保存，使用云端备份时会随账号备份上传。导入的气泡图片只存在这台设备，气泡替换和本地表情只有自己能看见。
