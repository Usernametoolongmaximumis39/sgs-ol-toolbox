# 账本

打开工具箱「信息 → 账本」，查看当前账号的余额、收入、消耗和物品变化。收支分别累计，列表的「较上次」显示已观察到的余额变化。

## 查看和导出流水

- 「详细账本」在工具箱旁展开流水，用叉或 Esc 关闭。「刷新配置」重新加载物品和奖励名称。
- 输入开始时间、结束时间、物品名称或完整 ID 可组合筛选。「全部登录／本次登录」切换记录范围，「全部日志／物品流水／祈愿台」切换记录类型。
- 点「上一页」「下一页」翻页。「具体日志 · 物品 ID 与记录详情」可展开该笔明细。「导出筛选日志」保存当前筛选结果，「清除筛选」恢复默认范围。

## 背包、预警与心愿

- 在游戏背包用「搜索道具」按名称筛选，也可按 Ctrl+F 聚焦搜索。回车或点放大镜搜索，按 Esc 或点清空按钮取消搜索。结果会随背包变动更新。
- 抵价券角标用「门槛-抵扣」标出条件。例如「100-20」表示满 100 可抵 20，实际使用条件以游戏为准。
- 展开「预警设置」，为可预警的物品设置最少减少量，填 0 关闭该项。达到设置会出现「重要物品减少预警」，点「知道了，立即检查」可关闭提醒并核对余额。
- 打开游戏的心愿武将或皮肤窗口，可查看当前进度和最近一批抽取的变化。详见[心愿进度](wish-progress.md)。

## 云同步与记录范围

未绑定云同步时，流水只保存在当前浏览器或微端。绑定后，登录时和在线期间每分钟会把账号资料、余额与流水同步到所绑定的服务器，也可点「同步账本」手动触发。清除本机数据可能丢失未同步记录。

账本从登录后观察到的变化开始记，首次读取背包不会算作收入。停用期间、断线或未观察到的变化可能缺失。到账及扣款请以游戏为准。
