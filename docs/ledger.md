# 账本

在本机按游戏账号记录收入、消耗和物品变化，分别查看收支汇总及流水。详情在工具箱旁展开，支持关闭和 Escape，可按时间、物品、登录范围和类型筛选、分页及导出。未绑定云同步时，数据仅保存在本机；绑定后，账号资料、余额和流水可同步至所绑定的服务器。停用期间无法补记，清除浏览器站点数据可能丢失记录。显示的变化不能替代官方到账和扣款结果，复杂奖励时序仍需核对。

打开游戏的心愿武将或皮肤窗口，可查看[心愿进度](wish-progress.md)；账本不代为抽取。
