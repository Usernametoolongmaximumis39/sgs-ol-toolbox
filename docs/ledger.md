# 本机账本

入口「信息 → 账本」。独立安装，无其他插件依赖，无云端同步或上传接口。

## 背包搜索与抵价券角标

- 启用账本后，在原生背包顶部增加道具名称搜索框和搜索／清空按钮。输入即筛选当前分类，忽略名称中的拉丁字母大小写；保留旧小抄的名称包含匹配规则。清空恢复当前分类全部物品，切分类保留关键词；零结果显示明确说明。背包打开时可用 Ctrl+F 聚焦、Enter 搜索、Esc 清空。
- 抵价券右上角显示“使用门槛-减免金额”，例如 `7000-2000` 表示满7000减2000。依据客户端的 `TypeID=98`、`usedeffect` 中的 `GRmb-AID` 和官方 `gn_dbs_coupon_cfg.sgs → sgs_config.couponsys.GRmb.seting[].AVV`，顺序与原生 `GetValue(0/1)` 一致。配置未就绪、未知类型或无有效金额时不显示、不从物品名称猜测。角标仅说明门槛和金额，不表示当前购买满足品类、时间等使用条件。有到期时间条时角标下移避让；不会拦截道具鼠标事件。
- 搜索仅过滤显示和分页，不改变原生物品列表；背包增删仍由原生监听处理。关闭、停用与卸载清理自有控件和快捷键。

「详细账本」由用户点击打开新页面，可按开始/结束时间、物品名称或完整ID、登录范围、物品流水/祈愿台筛选。每页100条，日志可完整展开；支持将筛选结果导出JSON。原始消息名、原因代码和去重依据放在具体日志中，不保存完整协议、账号凭据或登录对象。

日志保存在当前浏览器的IndexedDB：数据库`sgs-toolbox-ledger-v1`，对象仓库`records`，主键`id`，索引`account`。每条记录包含account、session、at、kind、source，以及投影后的items/祈愿信息；按账号读取，不设置静默截断或自动清理。浏览器清除站点数据会删除历史；空间不足或数据库错误会保留当前页内存、报告完整错误，并可先导出。

同一页面内停用/重新启用或插件升级保留会话标识并提示采集中断；重新登录、账号变化、整页刷新开始新的观察会话。历史仍按账号保留。首次启用无法追回本次登录早先的变化，界面始终注明“仅含已观察变动”。切换账号立即隐藏旧日志和余额，等待新账号的背包基线/货币通知后再显示余额。停用/卸载会释放所有原生监听、定时器、页面事件与主题订阅；不删除本机历史。

对比本次登录首次有效数量与上次在线最后有效数量；上次观测超过7天、缺少基线或数量未知时不告警。同次登录每种物品只提醒一次，面板关闭不停止观察。停用期间无法更新基线。

默认减少阈值：元宝5000、玉玺合计10枚、祈福灯30个、绘卷毛笔50个、秘钥50个；0关闭，已有自定义值保留。玉玺碎片按10片=1枚合并预警，库存和流水仍分别展示。如意结不参与阈值告警。元宝余额合计普通、绑定、限时元宝，任一分量未知则总额未知。

初始背包列表只建立基线，不计收入。收入和消耗分方向记录；通知与实例变动采用有限窗口关联以避免双记，不能保证任意延迟或交错时完全准确。祈愿次数与奖励只在各自有唯一候选时关联，未知时明确待核对，不强行配对。

首次启用、停用期间及未知实例的变动无法补记；空间不足或配置失败保留完整错误。记录只反映已观察变化，完整到账时序仍需官服复核。
