# 账本

在本机按游戏账号记录收入、消耗和物品变化，分别查看收支汇总及流水。详情在工具箱旁展开，支持关闭和 Escape，可按时间、物品、登录范围和类型筛选、分页及导出。数据保存在本机，不上传；停用期间无法补记，清除浏览器站点数据可能丢失记录。显示的变化不能替代官方到账和扣款结果，复杂奖励时序仍需核对。

## 开发历史

- ledger 0.3.7（2026-11-17）：随公共界面资源更新，账本统计、登录余额判断与物品提醒方式保持不变。


- 0.3.6（2026-11-16）：修复登录时余额尚未加载完整就误报大量元宝消耗的问题；修复部分微端物品减少提醒弹窗偏移、内容超出窗口的问题。
- 0.3.5（2026-11-16）：账本详情改为紧邻工具箱的侧边面板，支持关闭和 Escape；改善物品卡片、流水和筛选显示，保留本机账号数据与导出。
