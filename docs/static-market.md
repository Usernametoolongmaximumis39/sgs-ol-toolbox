# 插件市场与版本规则

市场用于查询、安装和更新独立插件。插件以稳定 ID、版本和 SHA-256 关联，下载失败或摘要不符时阻止安装／更新并显示错误；不自动删除用户数据。已发布同版本不得以不同内容覆盖。

## 来源与审核状态

| 来源／状态 | 获取规则 |
| --- | --- |
| 官方插件 | 正常搜索和获取，说明具体用途及风险 |
| 社区、仅机器初审 | 试用区默认隐藏，用户明确接受风险后查看并确认安装 |
| 社区、人工已审 | 普通社区列表可直接搜索和获取，保留审核范围 |
| 待审、异常、拒绝或撤回 | 不作为可安装版本提供 |

以上分级入口仍待客户端接入，不能把现有目录视为已经实现这些保护。完整规则和必要风险文案见[社区插件政策](community-plugin-policy.md)。

新版本独立审核。已审版本不静默升级到仅机器初审版本；风险变化或审核降级必须重新确认，取消则保留当前可用版本。前置安装遵守同样规则，不能绕过用户选择。撤回需明确受影响版本及原因，保留必要审核事实。

Full 与 Lite 的能力及数据规则见[发行版说明](distributions.md)。Full 随附集合与市场可用集合独立，市场上架不会自动改变随附内容。
