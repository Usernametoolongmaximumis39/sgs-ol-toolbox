# 自定义背景

把横版皮肤、游戏壁纸或本机图片用作牌局背景。先启用「皮肤管理」，再到工具箱「管理 → 外观 → 自定义背景」，也可从游戏的背景设置进入。

## 工具箱外观页

- 「背景播放」默认为「动态」，有可用动画时循环播放待机动画，否则显示原画。「静态」只显示图片。无需拥有皮肤或解锁动态。
- 「画质」可选「高」或「低」，影响支持的动态背景。低画质适合播放不流畅的设备。「攻击特效」控制支持的皮肤背景是否播放攻击动画。
- 「全局背景」默认关闭。开启后也会将选中的背景用于支持的非牌局界面。登录、加载界面和游戏特殊背景仍按游戏显示。
- 「一将皮肤」「手杀皮肤」打开对应的皮肤搜索，「本服皮肤管理」打开游戏皮肤窗口，也可按 Ctrl+Alt+K。在合适的横版或 16:9 皮肤详情点「作为牌局背景」或「设为牌局背景」应用。
- 「选择本地图片」支持 PNG、JPG、WebP、BMP 静态图片，最大 20 MB。选中即应用。「恢复游戏背景」取消当前替换。

## 游戏内背景设置

- 打开游戏背景设置的「自定义背景」页。可用皮肤入口挑原画，也可用「上传图片」选择本机文件。
- 「使用历史」列出近期用过的背景。点缩略图重新使用，「使用中」标出当前背景。「恢复游戏背景」切回游戏显示，出现问题可展开「查看错误详情」。
- 在游戏个性化里打开官方背景预览。出现「仅本地使用」时可把壁纸设为工具箱背景，点「取消本地使用」撤销。预览已在游戏中使用的背景时，若有工具箱壁纸覆盖，可点「恢复此背景」。

官方及外服图片、动画按需联网加载，部分皮肤只有静态效果。游戏触发的天气和技能背景优先显示。导入图片和背景使用记录保存在本机，替换效果只有自己能看见。
