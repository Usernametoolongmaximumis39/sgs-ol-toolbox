# 自定义背景

在外观页选择横版皮肤或适合作背景的原画，支持筛选与动态播放。默认优先播放动态资源，没有动态时使用原画；无需拥有皮肤或解锁动态。技能触发的背景保持优先。图片和动态资源需要联网加载，失败时可重试；不能保证所有皮肤都支持动态背景。

也可从游戏的背景设置选取近期使用过的背景，在个性化页面预览官方壁纸。导入的图片仅保存在本机，官方素材按需联网加载。

在外观页开启「全局背景」，可将已选背景应用到支持的非牌局场景。默认关闭，不替换登录或加载画面。
