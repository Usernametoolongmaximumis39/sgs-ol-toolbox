# 自定义背景

在外观页选择横版皮肤或适合作背景的原画，支持筛选与动态播放。默认优先播放动态资源，没有动态时使用原画；无需拥有皮肤或解锁动态。技能触发的背景保持优先。图片和动态资源需要联网加载，失败时可重试；不能保证所有皮肤都支持动态背景。

## 开发历史

- 自定义背景 0.2.8（2026-11-19）：适配皮肤管理中的背景快捷设置。背景图片和动态资源按需联网加载。


- 0.2.5（2026-11-16）：精简背景设置说明，统一开关与帮助提示的外观，保留已有背景和动态播放选择。

## 0.6.213 随附及市场更新

- 自定义背景 0.2.11。可从皮肤详情直接把支持的横版皮肤设为牌局背景。支持的动态背景循环播放待机动画，原画和动态资源按需联网加载。

## 0.6.223 随附及市场更新

- 自定义背景 0.2.12。动态皮肤背景可选高、低画质。低画质限制大型图集的分辨率，可减轻显存占用。动态素材仍按需联网加载。
