# 自定义牌局背景

核心 0.5.133；独立插件 `backgrounds` 0.2.1（最低核心 0.5.130）。必须先安装并启用“皮肤收集”（`skins`）。默认未选择背景；选择后默认启用动态，不要求账号拥有皮肤或已解锁动态。

- 支持视频（静音循环）、旧骨骼多角色分层、普通 Spine、现代 Spine 背景／人物／前景。多形态皮肤使用详情中选定的形态资源；是否可播放只看公开皮肤能力，不读取账号皮肤数、动态拥有、试用或预览选项。

先安装并启用“皮肤收集”，再启用“自定义背景”插件，打开游戏皮肤详情，点击原画左上角的“作为牌局背景”。保存当前皮肤形态的原画和公开动态资源，当前牌局立即应用，下一局自动沿用；大厅只保存选择。在「工具 → 自定义背景 → 背景播放」切换“动态 / 静态”，偏好保存在本机并用于后续选择。没有动态的皮肤显示原画；加载期间暂显原画，失败显示完整原因并回退原画，可切换或重新选择重试。工具分类中的“恢复游戏背景”清除选择。停用、卸载插件时撤销接入，保留选择供重新启用恢复。

核心负责资源校验、预加载、异步失效检查、当前场景接入、保存、恢复、状态订阅及插件生命周期。插件复用游戏皮肤模型的 `SkinBigUrl(juexingState)` 及原生动态路径，不写游戏个性化背景 ID，不发购买、升级或拥有状态请求。原画按真实尺寸等比完整显示并柔化补边；动画按原生预览设计尺寸等比显示，窗口缩放时重新适配。天气及其他原生背景仍沿用原生布局。旧版保存的原画在打开同一皮肤详情后自动补齐可识别的动态资源；也可重新点击“作为牌局背景”。

## 技能边界

仅包装当前牌局实例的普通背景方法和该实例已经订阅的 `BACKGROUND_USEDID_GOT` 方法引用；不修改背景层全局原型，不挂全屏遮罩，不强行轮询重画。

- 普通背景与个性化背景 ID 选择改用已预加载的自定义原画。
- `currentWeatherWallPaper` 非零时让原生天气背景执行；恢复普通背景时再应用自定义原画。天气添加、移除和动画方法不被拦截。
- 外部 `SetWallPaperByUrl` 或带 URL 的 `SetWallPaperById` 原样执行，并暂让出控制，直到原生恢复普通背景。
- 裴秀等武将的 `SpecialBackground` 是原生背景层上的独立子控件。此功能不删除、隐藏、遮挡或重排这些控件，不改其资源加载、显示、隐藏、点击与地图逻辑。
- 技能背景期间停用插件，不强制重新绘制背景。离开牌局只释放旧场景包装，不向大厅重画旧背景。
