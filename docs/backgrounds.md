# 自定义牌局背景

在游戏原生皮肤详情中选择可用的横版或动态皮肤作为牌局背景，支持筛选与预览。自定义背景依赖皮肤收集插件；仅浏览详情不会下载全部背景。

图片按原始比例铺满并居中裁切，随画布尺寸调整。皮肤详情提供下载按钮；点击后读取当前觉醒状态对应的图片，保留文件格式，不上传账号信息。下载失败可查看完整详情。

裴秀等技能切换背景时保留游戏原生行为。离开详情、关闭窗口或开始退出动画时隐藏自有控件；重新进入后恢复。关闭、停用或卸载时释放自有资源。

部分素材和完整技能组合尚未完成官服验证，动态素材可用性以当前客户端为准。山河战斗背景的独立设置见 [山河战斗背景](shanhetu-background.md)。
