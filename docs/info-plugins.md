# 百胜战功与出框胜率统计

两个插件都在工具箱「信息」页，分别用于查游戏战功和记录自己的对局。

## 百胜战功

- 「刷新战功」向游戏查询当前账号的任务进度。「导出」下载该账号已保存的战功数据。
- 在「全部」「未完成」「已完成」间切换，再用「已拥有」「全部武将」缩小或扩大范围。「搜索武将或战功」可按武将名、战功说明或技能说明找条目。
- 进度缺失时显示未知。「已拥有」视图暂时保留拥有状态未知的武将。遇到异常可展开「数据异常 · 查看详情」。
- 断线时仍可看和导出本机已保存进度，游戏连接就绪后可刷新。进度按账号保存在本机，查询只向游戏服务器读取。

## 出框与胜率统计

- 「查看详情」打开大面板，点关闭按钮返回。「统计总览」查看出框率、选取率与胜率，「对局历史」查看保存的对局。点「加载更多」继续浏览。
- 选择「排位」「斗地主」「单骑」后，可按该模式的身份或先后手查看。排位 1、4 号位为先手，2、3 号位为后手。输入武将名可筛选。
- 展开「筛选与排序」可设最少出框或出场次数、开始和结束时间。总览可按胜率、胜场数、出场数或出框数排序，可从高到低或从低到高排列。
- 「刷新」更新武将名称并尝试补收官方最近七日战绩，登录和开始下一局也可触发。「导出」保存当前账号本机记录。「恢复工具箱备份」可选本账号的工具箱导出文件。「清空本机记录」会再要求确认，点「取消」放弃。
- 看见记录提示可点「知道了」。展开「统计口径与数据记录」查看适用模式。保存异常可展开「记录异常 · 查看详情」，并点「重试保存」。
- 绑定云同步后，可用「同步出框与战绩」。同步会向所绑定的服务器发送经游戏对局编号核实的战绩及相关出框。未绑定时记录按账号保存在本机。

出框目前记录正式排位、斗地主基础与高级场、单骑无双。训练、观战、回放和已确认的人机局不计入。胜率按明确胜负计算，平局和未知结果不计入。停用或断线缺失的出框无法补记。官方战绩只补已在本机记录到开局且能确认归属的对局。出框与战绩各最多保存 10000 条，满后暂停追加。
