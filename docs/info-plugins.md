# 百胜战功与出框胜率统计

百胜战功可查询当前账号的武将战功进度，按拥有情况和完成状态筛选、搜索及导出；查询需要连接游戏服务器，未知进度会明确提示。

出框与胜率统计在启用期间记录正式排位、斗地主基础／高级场和单骑无双的候选、选择与战绩，按模式、身份、先后手分组。可打开独立详情窗口筛选排序和查看历史。训练、观战、回放和明确人机对局不计入；人机身份未知时会提示，不凭昵称猜测。胜率只使用明确胜负，平局和未知结果不计入。

两者记录均按账号保存在本机，不上传、不跨设备同步。停用期间和消息缺口不能补采；旧出框不能补造胜负。缺少身份或先后手的旧记录会被剔除，记录达到上限后暂停追加，不静默替换历史。详情导出前请核对筛选和账号。

- 出框与胜率统计 0.4.18（2026-11-16）：新增独立详情窗口及更清晰的筛选排序，按模式和身份统计胜率；修正正式模式与人机识别，缺少身份或先后手的旧记录会被剔除。仅采集启用期间的本机记录，不上传。
