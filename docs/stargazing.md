# 自助观星

在工具箱「工具 → 自助观星」中点击「打开观星」，即可查看第三方观星站的活动预测。可以按栏目浏览、用关键词搜索，也可以手动刷新。预测仅供参考，活动时间和奖励以游戏公告为准。

插件需要工具箱核心 0.6.180 或更新版本。核心 0.6.213 起，若当前账号已绑定支持接管观星的同步服务器，且管理员开启接管，工具箱通过该服务器读取报告。这个请求使用现有绑定授权。同步服务器统一匿名读取观星站报告。未绑定或接管关闭时，工具箱直接匿名读取观星站。两种方式均无需上传游戏账号、牌局或剪贴板数据。

连接失败时可通过窗口底部的来源链接访问观星站。私有 HTTP 同步可能需要更新微端接入层。

## 开发历史

- 0.1.0（2026-11-20）首次公开，支持按栏目和关键词查看活动预测。

## 0.6.213 随附及市场更新

- 自助观星 0.1.1。更新观星窗口和入口样式。绑定支持接管观星的同步服务器后，核心可使用现有绑定授权通过该服务器读取报告，其他情况下直接匿名读取来源站。
