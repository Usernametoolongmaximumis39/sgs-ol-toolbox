# 自助观星

在工具箱「工具 → 自助观星」点「打开观星」，查看第三方观星报告。

- 「选择栏目」可以只看指定栏目，选「全部栏目」恢复。输入「搜索关键词」会在当前范围找内容，清空输入可取消筛选。
- 点「刷新观星报告」获取最新内容。刷新失败时，如有上次读取的内容会继续显示。页面会注明数据更新时间或提示来源未提供时间。
- 点报告条目中的来源链接可查看原文，窗口底部的来源站链接可直接打开网站。点关闭图标退出。

查看报告需要联网。未绑定支持观星的云同步服务器时，工具箱直接匿名读取来源站。绑定的服务器支持观星时，工具箱可使用已有的绑定授权，通过该服务器读取报告。报告内容可能调整，以游戏官方公告为准。
