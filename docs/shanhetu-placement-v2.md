# 山河图

进入山河图地图后，打开工具箱「牌局 → 山河图」，查看地图、商店、流派和结局。标题旁的「重新同步山河数据」会重读当前进度及游戏配置。标题下可看难度、行军月份和铜钱。

## 四个页签

- 「地图」列出节点及当前、完成状态。点节点展开敌将、阶段、体力、护甲、需要留意的技能、奖励和事件选项。游戏地图上的「…」可打开拥挤节点的详情。详情中用「上一页」「下一页」翻看，较长内容可滚动，点「×」关闭。
- 「商店」可预览已取得的商品、品质、价格和购买状态，点商品展开说明。已关注套装中尚未购买的战法带星标并靠前显示。「打开商店」进入游戏商店，购买和刷新仍按游戏规则执行。
- 「概况」显示初始体力、体力上限、初始牌、摸牌数、护甲、出杀次数与伤害数据。点「已有战法」下的条目可读说明。「流派进度」显示各品质凑齐的数量；点「关注」或「取消关注」可增减提醒。打开游戏集市或选择战法时，也可看到关注提示。
- 「拓展」显示结局倾向、达成条件、已确认的战绩分或当前战败结算预估。展开条目查看依据，加载失败可点「重试」。若关闭了该功能，点「启用拓展」即可恢复显示。

## 显示设置

| 开关 | 打开后的效果 |
| --- | --- |
| 地图标注 | 在游戏地图上补充节点提示 |
| 敌军标注 | 展示敌将、可读到的战斗数值和重点技能 |
| 问号与事件标注 | 展示问号节点和可识别的事件选项 |
| 数值变化标注 | 展示有依据的选项影响，默认关闭 |
| 战绩分与结局倾向 | 显示「拓展」中的分数和结局信息 |
| 保留自选战斗背景 | 进战斗时重新使用当前自选背景，默认开启 |

换将卡相关窗口会在能读到候选时显示[换将卡预判](shanhetu-general-preview.md)。自己的战法图标可以显示[战法计数](shanhetu-tactic-counts.md)。详见[地图信息图标](shanhetu-icons-performance.md)与[战斗背景](shanhetu-background.md)。

敌军数值和军饷估值会参考难度、月份和路线。部分奇遇数值参考第 5 赛季的记录，缺少可靠信息时标为待确认。结局和战绩分以游戏结算为准。买商品、刷新商店或换将前请核对游戏提示中的铜钱、道具和其他消耗。
