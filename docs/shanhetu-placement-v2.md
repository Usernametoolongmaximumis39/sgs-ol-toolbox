## 0.2.4：上方优先、允许原生 UI 交叠与卡片改造

本轮按用户最新截图和明确要求调整此前规则：完整卡片优先贴近自己城市上方；无法采用上方时允许以自己的城市为中心覆盖呈现，其次使用其它附近位置。原生 UI 改为覆盖面积和引线穿越的软代价，不再单凭控件相交就拒绝卡片。其它城市、其它卡片、详情抽屉以及可见画布边界继续硬检查；不得把自身城市的覆盖例外扩大到相邻城市。

浮卡 UI 使用半透明主题底、独立标题和弱化编号、正文层级及奖励分隔；只有背景透明，正文保持清晰、不缩字、不省略阶段、防具、警告或奖励。绘制层位于当前地图场景内的原生控件上方，保留 cityView 的完整变换和可见裁剪；浮层不接管鼠标操作，HTML 详情抽屉仍阻止点击穿透。

完整浮卡数量仍优先；在同等数量下先比较自然上方数量，再比较自身覆盖数量，然后权衡贴靠居中、UI 覆盖与短引线，保留稳定位置及 ID 同分顺序。全卡已经能放下但位置不在上方时，也会按需要实测其它换行宽度，并以同一布局评分选择整组。候选和最终绘制均独立复核，不能用重叠两张卡解决空间问题。

自身覆盖要求卡片中心落在城市主体中央半宽/半高范围，且相交面积达到双方较小面积的一半；不能凭借“碰到城市边角”放宽避让。普通控件几何暂未就绪时仍继续浮卡布局，保留待补测及覆盖不完整的明确诊断；真正城市贴图、名称或事件标记未就绪仍等待。

以下旧版本记录描述当时的约束与结果；原生 UI 的硬避让已被本节规则替代。本轮验证结果如下。

## 0.2.3：让完整卡片适应实际空位

用户实图显示 5027 仍进入抽屉。本次将上一轮没有解决的“官方坐标下两张浮卡、一张抽屉”设为必须通过的验收。固定 220×147 的卡片无法通过该区域的归属与避让检查，但保持原字体字号、完整内容重新换行为 170×165 后存在合法位置；固定卡宽不再被当作必须进入抽屉的理由。

`map-labels-v2.js` 先按默认 220 宽或上次采用的宽度排完整卡片。只有存在溢出时，才实测 160/170/190/220/250/280/320 七种宽度的完整内容；先为遗漏卡尝试，再按需要扩展整组。只有完整浮卡数量增加才采用新方案，默认已经放下的整组不无意义改宽。未被采用的测量 Sprite 及时销毁，异常时也完整释放；提交时核对实际 Sprite 宽高与布局输出完全相同。

`placement.js` 的插件内部输入增加可选 `alternatives` 实测尺寸对，最多七组。纯布局只能选择已经测量的整对宽高，不能自行估算缩高、拼接不同选项的宽高或伸缩文字。候选保留各尺寸与方向，排序仍为完整卡数量、短引线、少位移，最后才以少改宽等条件稳定同分。原有归属、节点/原生控件、边界和引线硬检查不变，没有新增核心公共 API。

主验收继续加入原生头像标记 56×73 及官方定位、擂台主体 86×71、名称底板 152×107 和名称框 100×20，来源及公式见同目录 `player-raid-geometry-evidence.json`。这四块实际控件均参与保护，不能省略后宣称全卡可放。1299×739 深浅场景最终为 5026=220×148、5027=170×165、5028=190×111，三张浮卡、无抽屉；此组合实际走过“遗漏卡改宽仍失败，再整组改宽”的第二阶段。张绣卡位于城市左侧，避开上方头像及下方擂台，已查看两张截图。

## 0.2.2：空白区域仍全部进入抽屉

用户再次反馈三张卡全部进入抽屉。不能据此声称地图空间不足。本次确认并修复了两类独立问题：

- **整张地图被空静态标记阻塞。** 官方 `UZt.clearBossEffct()` 在 Boss 出场后调用 `a8t.ShowBossIcon()`，它无条件将 `eventtypeImg.visible` 设为 true；正常可战斗的 Boss 使用 `eventEffect`，静态 `eventtypeImg` 可以没有 texture、宽高为零。原采集器将它永久列为未就绪，renderer 因此把全部卡片送入抽屉，根本没有调用安放搜索。新例外仅限该已知静态标记且无贴图、零尺寸、无子项及绘图指令；有实际内容但尺寸未知、真正未加载的城市主图仍等待。
- **合法空白中间位置被漏搜。** 原候选只取障碍边界；边界位置可能与邻城等距而被拒绝，但同一空白区域内部有合法位置。新候选在原有短引线范围和整卡边界内补相邻边界的中点，独立于原 32×32 边缘预算；归属、节点/控件避让、整卡边界及引线约束均未放宽。最小反例有独立合法位置见证，原候选 289 个、合法 0，修后 310 个、合法 4。

同时核对真实可见性：Laya 将传入的 visible 原样保存，官方无城名时写入空字符串，原来的 `=== false` 检查会把隐藏底板当作障碍。现在按属性存在性及真实布尔语义判断；官方 `fO.EmptyTexture` 仅绘制 .01 的占位图也不再作为整块装饰障碍，主城市图仍按未加载处理。

内部诊断保留具体待就绪字段、完整卡片实测尺寸、初始求解与每次抽屉重排的候选/拒绝原因，不再被最后一次空集合求解覆盖。没有新增核心公共 API。

## 0.2.1：修正实际客户端不显示

0.2.0 在用户截图中发生回归：面板有数据，地图卡片与兜底抽屉都未显示。原演练错误地给 `html/body` 设置了 `height:100%`，并把原生扁平按钮简化成普通 Sprite，漏掉两项实际客户端条件。

- 官方页面使用绝对定位画布，`html/body/layaContainer` 可全部为零高度。HTML 的双轴 overflow 为 visible 时，BODY 的 overflow 传播到视口，不能拿其零高度盒裁剪画布。新采集器按该规则取浏览器视口，并继续保留普通 div 与不发生传播的 BODY 的实际裁剪。
- 官方帮助和集市按钮是 `$jt extends EO`，具有渲染位置却没有 `renderWidth/Height`。新采集器仅对明确的 `IsFlatButton` 读取其真实 `fO background`；该图元已包含按钮变换，不重复叠加坐标。否则会把常驻帮助按钮永久列为几何未就绪。
- 采集结果增加明确的失败原因和纯几何诊断。持续无法显示时上报一次可查看的错误，提示已同步内容仍在山河图面板；恢复后清除错误，初始化短暂等待不会反复报警。

证据来自上述官方缓存的完整 `fO/EO/$jt` 类声明与原始 getter（固定 SHA-256，不执行构造器、客户端启动或业务网络），以及真实 Chromium + Laya 演练。默认演练已移除根元素高度修饰，确测三个 DOM 元素均为零高度，仍显示 4 张卡；还覆盖 CSS 缩放、偏移、普通容器裁剪、失效视口持续 1.7 秒后提示与同一实例恢复。

本次发布山河图 0.2.1，核心构建 0.5.57。修复位于独立插件，已有符合契约的核心可直接更新插件。迁移仅新增实际验证的 0.2.0 包摘要 `9017d32206a5b0e4e2eeede12e390767620579836ed7037e1e223f7ab0c52483`，继续保留停用与回退。最终包、市场、静态副本和源码一致性见 `release-verification.json`。

## 新实现的约束

- `placement-geometry.js` 统一转换到 cityView 坐标，求交场景明确尺寸、祖先及舞台 scrollRect、实际 canvas 和浏览器可见裁剪；处理 DPR、stage transform、pivot、父级缩放及 CSS 裁剪。不能确认的旋转、mask 或图元几何停止浮动布局，不猜坐标。
- 城市保护包含实际主图、名称、奖励和事件标记；无事件但可见的城市也参与保护。动画特效大小不改变城市主体。原生操作区只采集已确认图元；城市几何不明确时等待，普通控件未测出时保留待补测诊断并继续安放，避免将软条件变成全图隐藏条件。抽屉只能避让已测控件，不能据此声称未测控件也已被保护。
- `placement.js` 只接收纯快照。整卡在画布内保留 8 逻辑像素边距；节点保护间距 8，普通贴靠候选间距 12；明确的自身覆盖候选仅豁免自己的节点。原生控件采用软代价，抽屉仍为硬障碍。卡片到自己主体的矩形距离必须严格小于其他主体；等距拒绝。引线不能穿其他节点、卡片、抽屉或引线，且长度不超过卡片宽度；自身覆盖使用规范的零长度引线。
- 整体搜索优先完整卡数量、自然上方、自身覆盖，然后比较贴靠与 UI 覆盖代价、引线长度及位置变化；稳定 ID 决定同分顺序。搜索有明确预算，失败只表示“未找到合法位置”，不声称证明无空间。搜索结束和提交绘制前都复核硬条件，没有强放路径。
- `map-labels-v2.js` 测量全部内容后才布局；所有文字正常换行，不通过缩字、删行或截断腾位置。保留警示技能文字。上次几何和内容相同不重绘，普通点击不触发跳边。

## 完整详情抽屉

无法合法安放的卡片进入画布内可收起抽屉，显示城市名称与 ID，正文完整且可滚动。展开允许遮住地图内容，阻止点击穿透，避开原生操作区；抽屉自身成为其余浮动卡片的障碍。同一轮溢出集合只增加，避免布局振荡。

标题固定单行，窄宽使用短标题和动作，并保留完整无障碍名称。展开优先选择至少 96 高的区域，保底至少 58 高、96 宽；收起栏高 34。极小窗口只够标题而不够可读正文时，明确停用展开并提示放大窗口或到工具箱山河图面板查看，不伪装成已经显示完整内容。

纹理完成、显式原生布局方法、窗口适配和有界快照检查触发更新。旧场景监听释放；销毁、停用、卸载及异常建卡时清理自有对象、样式、DOM、计时器和原生包装。
