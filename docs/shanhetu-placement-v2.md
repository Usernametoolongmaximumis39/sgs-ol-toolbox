# 山河图

在山河场景显示地图、敌军、事件与相关信息，并提供换将预览、商店入口及刷新操作。可分别开关标注；战斗中默认保留自选背景，已有设置保持不变。军饷估值结合当前难度和路线计算，仅供参考，不保证通关。购买、换将等实际操作仍以游戏提示及道具消耗为准。

在「概况」可查看流派进度和关注套装。另行安装山河图拓展（Beta）后，在「拓展」可查看结局条件和战绩分预估。部分奇遇数值根据第 5 赛季历史记录显示，缺少可靠数据时会提示待确认。实际战绩分以游戏结算为准。

## 开发历史

- 山河图 0.2.42（2026-11-19）：概况新增流派进度与套装关注，支持在集市和选战法时提示关注的战法。可开启奇遇数值标注。换将预览在微端按游戏区域居中，避开工具箱侧栏。
- 山河图拓展（Beta） 0.1.13（2026-11-19）：首次公开测试。安装山河图后可在「拓展」查看结局倾向、战绩分和战败结算预估。第 5 赛季有历史记录的奇遇可显示数值变化，分数以游戏实际结算为准。


- 0.2.29（2026-11-16）：保留自选战斗背景改为默认开启，已有明确设置保持不变；精简地图设置和帮助说明。
