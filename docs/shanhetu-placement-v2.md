# 山河图

在山河场景显示地图、敌军、事件与相关信息，并提供换将预览、商店入口及刷新操作。可分别开关标注；战斗中默认保留自选背景，已有设置保持不变。军饷估值结合当前难度和路线计算，仅供参考，不保证通关。购买、换将等实际操作仍以游戏提示及道具消耗为准。

在「概况」可查看流派进度和关注套装。在「拓展」可查看结局条件和战绩分预估，无需另行安装山河图拓展。部分奇遇数值根据第 5 赛季历史记录显示，缺少可靠数据时会提示待确认。实际战绩分以游戏结算为准。

地图空间不足时，节点详情可翻页或滚动；部分节点只显示入口，点击旁边的「…」可展开详情。
