# 特效屏蔽

插件 ID：`effects`，入口：工具 → 特效屏蔽。对局12项默认折叠，0–5档滑条控制屏蔽程度；下方两行六项合并按钮。每项直接显示「已屏蔽／未屏蔽／部分屏蔽」，配合滑轨位置区分状态；悬停提示下一次点击的动作，原有保留项目的设置继续兼容。

第一档只屏蔽老仙动画；第二档增加己方／他人皮肤；第三档增加选中、震动、击杀；第四档增加武将；第五档全部屏蔽。滑条仍保留0档与右侧详情，独立调整会显示自定义。

下方固定三列两行：狗卡广告（首页横幅、版本公告、下载入口、狗托弹幕、开屏广告）；任务红点；进房特效（势力口号、玩家进房）；动画表情；出货动画（开包、获得展示）；过场结算（山河过场、局后结算）。充值按钮移除和昵称显示屏蔽已从设置与适配代码删除，旧值不会生效。

关闭单项、全部恢复、停用、卸载均撤销所属包装器与显示覆盖，恢复最新原生显示意图。已关闭的窗口不补播。出货窗口排队中的关闭在停用／卸载后取消，调整无关开关不丢失其收尾状态。后装第三方包装器保留，旧包装层失效。

通用动画和皮肤／入座／首领动画仍执行原方法，保持接收者、参数、返回值、异常、命中与结束回调。只隐藏专用节点，避免卡住原生完成流程。因此不承诺减少资源下载、加快所有动画或提高帧率。装饰、震动、击杀奖励展示等已核对的纯展示入口可阻止新启动；正在执行的震动正常结束。铁索、酒及封印持续状态标记保留。

「等待界面」表示尚未找到该类入口；「已接入」只表示方法／节点已适配，处理次数也不代表全模式实局验收。未知资源和未知结构保持原样。没有把广告、抽奖或结算窗口的逻辑替换成领奖、购买或自动出牌请求。

每 750 毫秒检测，显示树最多 512 个节点，事件监听者最多 512 次，座位最多 16 个；单次扩展检查最多 2048 个对象，红点树最多 512 个节点，获得窗口收尾最多跟踪 128 个，专用显示覆盖最多 256 个。全关不扫描游戏对象。不调用原生单例工厂、不构造游戏窗口、不清理全局计时器、不发送网络请求。

公告与未首充发财树提醒可按设置隐藏；只处理已识别的展示入口，任务、购买、领奖及原生队列逻辑保持原值。关闭或停用后恢复最新原生显示意图，已关闭窗口不补播。未知素材和结构保留原生行为；完整武将、过场和弹窗组合尚需官服验证。
