## 0.2.2 广告误关所有窗口修复

用户反馈开启「开屏广告」后其他界面全部打不开。原因是窗口适配器沿原型链寻找 `showHandler`、`enterWindow`、`UpdateWindow` 的定义位置，并把广告关闭逻辑装到共用父类。普通窗口也经过这些入口，因此被误关。同时 `showHandler` 位于原生初始化流程中间，立刻关闭会打断后续监听注册。

修复后，窗口拦截只在具体窗口类的原型或已确认的窗口实例上添加覆盖，带接收者范围检查，共享父类保持原样。广告、版本公告、结算、开包、山河对白、出货、天书适配统一采用此限制。弹窗关闭仅在最外层 `enterWindow/UpdateWindow` 成功结束后执行，不再改写共用 `showHandler`。广告只走一次自己的 `Close`，不再循环调用每个广告视图的整窗关闭；已移除的窗口不重复关闭。已打开窗口通过精确 name 定位时，也只处理该实例。

本地官方缓存中的 `r8i`（广告）继承 `Bqi/Wjt`，其中 `Wjt.enterWindow` 先调用 `showHandler`，再注册监听，广告类在 `super.enterWindow` 后继续初始化。这是本次检查关闭时机与作用范围的静态依据，缓存哈希见下文。

上述为按原生继承关系构造的浏览器回归，未替用户在真实账号页面复测。

## 0.2.1 现场反馈修复

用户实测发现：充值按钮不能点但仍可见，顶部弹幕完全未隐藏。0.2.0 的合成对象没有覆盖原生绘制缓存和混合字典，不能据其测试通过宣称这两项在真实页面已实现。

- 官方 `fO.visible` 会先比较 `this.visible` 再执行原生 setter 与绘制失效通知。旧拦截在 setter 执行前就让 getter 返回 false，原生判断因此跳过了更新；只改变逻辑可见性，未更新缓存图形。现在原生 setter 执行期间读取真实底层值，完成实际隐藏／重绘；关闭或卸载也通过原生 setter 恢复。此修复同样用于横幅、昵称等可见性覆盖。
- 充值按钮在工具栏布局前隐藏，保留原生 hideList、其他按钮和右侧边界，收拢空位；关闭或卸载后重排恢复。
- 官方 `SNt` 同时有 `_maps` 与 `_objDatum`。旧读取器看到空 `_objDatum` 就返回，漏掉 `_maps` 中的普通／活动弹幕。现在合并两个存储区并限制读取数量；字典已有、刚创建和后续更新的弹幕均覆盖，保留原生队列与完成回调。对游戏已保存的活动监听函数，另在专用管理器的 addChild 时立即隐藏字典内的新节点，不等待750毫秒轮询，也不隐藏其他提示。通用特效旧实例扫描也使用同一修复。

`npm run test:browser-effects` 在独立临时 Edge profile 中，从历史工具箱 0.2.4 只抽取原 effects 模块重现这两个缺陷，再安装 0.2.1 对比。画布分别绘制充值、商店、普通弹幕和活动弹幕：旧版屏蔽后四处像素 alpha 均为 204，充值逻辑 visible 已为 false；新版充值和两类弹幕 alpha 均为 0，商店仍为 204。工具栏宽度 210 → 105，右边界保持 610；关闭与停用后恢复。新生成弹幕、原生完成计数及 alpha 更新也通过。

静态依据补充：从同一官方缓存只读抽取 `fO`、`SNt`、`CZt` 与工具栏类，REA 保留证据 `ev_26d519b09fcdb61237256f510943b17a9b6915ccf4589af5f7709a00ca137b8d`。解析覆盖受节点上限限制，仅用于核对上述局部方法；未运行官方客户端或原版小抄。

## 恢复与适配边界

关闭单项、全部恢复、停用、卸载均撤销所属包装器与显示覆盖，恢复最新原生显示意图。已关闭的窗口不补播。出货窗口排队中的关闭在停用／卸载后取消，调整无关开关不丢失其收尾状态。后装第三方包装器保留，旧包装层失效。

通用动画和皮肤／入座／首领动画仍执行原方法，保持接收者、参数、返回值、异常、命中与结束回调。只隐藏专用节点，避免卡住原生完成流程。因此不承诺减少资源下载、加快所有动画或提高帧率。装饰、震动、击杀奖励展示等已核对的纯展示入口可阻止新启动；正在执行的震动正常结束。铁索、酒及封印持续状态标记保留。

「等待界面」表示尚未找到该类入口；「已接入」只表示方法／节点已适配，处理次数也不代表全模式实局验收。未知资源和未知结构保持原样。没有把广告、抽奖或结算窗口的逻辑替换成领奖、购买或自动出牌请求。

每 750 毫秒检测，显示树最多 512 个节点，事件监听者最多 512 次，座位最多 16 个；单次扩展检查最多 2048 个对象，红点树最多 512 个节点，获得窗口收尾最多跟踪 128 个，专用显示覆盖最多 256 个。全关不扫描游戏对象。不调用原生单例工厂、不构造游戏窗口、不清理全局计时器、不发送网络请求。
