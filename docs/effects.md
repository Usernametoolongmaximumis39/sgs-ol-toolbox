# 特效屏蔽

在工具箱「工具 → 特效屏蔽」可隐藏影响自己视线的对局动画、广告和其他提示。设定只影响本机看到的内容。

## 对局特效

滑动「对局特效」可逐档加屏蔽。0 为无屏蔽，然后依次增加老仙动画、皮肤动效、选中／震动／击杀、武将特效，拉到「全部」时屏蔽本组所有项目。点「详情」可单独点选，点「收起」合起列表。「自定义」表示手动选择的组合，移动滑杆会换成该档预设。

可单独选择选中特效、杀特效、闪特效、锦囊特效、装备特效、受击特效、回血特效、击杀特效、武将特效、己方动效、他人动效、老仙动画。老仙动画指其他玩家南华老仙书写天书的动画。

## 其他屏蔽

| 项目 | 控制的内容 |
| --- | --- |
| 狗卡广告 | 首页横幅、版本公告、下载入口、狗托弹幕、开屏广告 |
| 任务红点 | 任务、活动及更多菜单的红点 |
| 进房特效 | 支持的势力口号与玩家进房动画 |
| 动画表情 | 其他玩家的动画表情 |
| 出货动画 | 开包、祈愿、抽奖等获得物品的展示 |
| 过场结算 | 山河过场、局后结算及 MVP 展示 |

点卡片可屏蔽或恢复。「部分屏蔽」表示该项包含的内容只有一部分在屏蔽中，再点会全部屏蔽。「重新检测」重新识别当前游戏界面，「恢复全部显示」取消所有屏蔽。部分规则要等相应界面出现才生效。
