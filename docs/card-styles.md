# 卡面卡背拓展

打开工具箱「管理 → 外观 → 卡牌外观」更换牌的正面和背面。该页面随工具箱提供，启用「卡面卡背拓展」可选官方经典、官方大将军、金色卡牌、一将成名和大肥鱼外观。安装后需自行选择。

## 选择外观

- 点「卡牌外观」标题展开或收起。「卡面」「卡背」可分别点预览卡选用，两面可以混搭。各自点「跟随游戏」可恢复该面的游戏外观。
- 「应用范围」可选「仅自己」或「所有人」。「仅自己」作用于自己的手牌，以及这些牌被使用、打出或被顺走时的显示。「所有人」也会替换本机看到的其他玩家卡牌。
- 选中整套图片的卡面后可点「查看图集来源」。提示加载失败时可点「重新加载卡面」。部分样式立即有预览，其他图片要在选用后加载。

## 使用自己的图片

- 选「自定义卡面」后可切换「统一底图」与「逐牌换图」。统一底图让支持的牌共用底图，保留游戏牌名和插画。逐牌换图使用你为该牌指定的完整图片。
- 逐牌换图可用「搜索牌名」缩小范围，再从「已换图」或「可换图」选一张牌。点「选择图片」或「更换图片」导入，垃圾桶可「删除这张卡图」或「删除底图」。牌名列表读取失败时可点「重试读取牌表」。
- 「自定义卡背」的「选择图片」会添加并应用卡背。可用 JPG、PNG、WebP、BMP 静态图片，最大 20 MB，图片会居中裁剪。点已保存卡背的缩略图应用，点旁边的垃圾桶删除。选择「跟随游戏」可恢复游戏卡背并保留已导入的图片。

换装只在本机可见。部分套装首次使用时联网加载，部分官方套装需等游戏加载资源。未覆盖的牌、部分特殊牌或加载失败的牌沿用游戏外观。停用套装插件会暂时恢复游戏外观，再启用时可恢复选择。
