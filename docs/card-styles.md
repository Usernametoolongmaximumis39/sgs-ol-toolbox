# 卡面与卡背
核心 **0.5.117** 提供逐牌完整卡图接口，并新增独立「一将成名卡面包」（喵喵杯／猪猪侠）。来源、资源声明、加载方式与特殊牌回退见 [专门说明](yjcm-cards.md)。原有底纹样式和卡背选择继续保留。

## 官方原生套装

新增独立无前置的「官方卡牌」插件，和自绘「金色卡牌」并列。设置入口不变，提供「官方经典」「官方大将军」两项。安装不自动更换选择，停用、卸载及回退继续遵循核心恢复语义。

| 套装 | 官方卡面 | 官方卡背 |
| --- | --- | --- |
| 官方经典 | `cardFace_0` | `cardBack_0` |
| 官方大将军 | `cardFace_10` | `cardBack_5` |

编号依据本机官方 `sys_appearance.sgs` 的 `CardsShow` 解码结果；`type: 2` 是卡面，`type: 1` 是卡背。大将军正反面编号不同。月卡套装不在当前两套原生外观范围内。

接口新增 `ctx.cardStyles.register({id,name,native:{face,back}})`，与原有色板形式互斥；face/back 只接受 `cardFace_数字` / `cardBack_数字`，无任意 URL。原生图集解析 `parseAtlas` 以帧文件名去扩展名建立资源名；核心从 `Laya.Loader.textureMap/loadedMap` 查找同名 PNG 子纹理，并兼容直接资源名。只借用已加载的原生纹理，不修改尺寸、不销毁游戏资源，不依赖旧小抄；原生资源加载后会自动补上预览。卡面与卡背分别等待各自的资源；未就绪的一面保留游戏外观并显示等待状态。预览按原生 `getTexturePixels` 读取，不用自绘图片冒充官方资源。

管理 → 设置 → 主题工坊下方的「卡牌外观 / 卡面与卡背」。展开后选择「金色卡牌」；选择「跟随游戏」恢复原生外观。折叠状态与套装选择分别保存在本机。安装套装不自动改变选择。设置／插件市场切换栏在内容滚动时保持置顶。

金色卡牌 0.1.0 为独立无前置插件。纹理绘制、原生对象发现、方法包装、设置 UI、状态与恢复都属于核心；插件只提交色板，不依赖卡牌记录、主题包或旧小抄。

最低核心 `0.5.90`，`categories: []`，使用 `ctx.cardStyles.register({id,name,face,back})`。ID 须以前缀 `插件ID.` 开头，名称不超过 48 字符；face/back 各含 `base/light/edge/ink` 四个六位十六进制颜色。核心复制并冻结数据。注册返回幂等清理函数，核心自动绑定到插件 scope。

另有 `list()`、`select(id)`（空字符串恢复原生）、`subscribe(fn)` 和 `current`（持久化选择 ID）。停用／卸载套装立即恢复原生显示，保留所选 ID，重新启用可恢复选择；已关闭 scope 的注册／订阅／选择无效。不可用套装在设置中显示回退状态。

依据本机官方客户端 `NormalCardUi` 的 `SetCardFace`、`getCardFaceBaseTexture`、`updateNewCardFace` 结构识别已有对象，不依赖混淆类名。遍历显示树及已核实的 `cardUis/cardUIs/seatUIs`、牌容器字段，不遍历账号、牌堆或其他模型。核心 0.5.99 起优先包装已有容器的 `createNormalCardUi`，返回卡牌给原生调用方之前立即接管；再从已确认卡牌的构造器找到其实际 `pool/flatPool` 实例，包装 `BorrowObject/returnObject`，使复用卡在赋牌前接入、归还时释放。仅包装这些实例，不改全局原型。场景切换触发重新检查；400ms 巡检只作发现未知容器和清理对象的兜底。原生 `SetCardFace` 仍先执行，再在同一次调用内替换底纹。真实资源尚未加载时仍保留原生外观，不能凭空保证冷加载零等待。

使用原生 `Laya.Texture2D/Texture` 绘制 93×130 的卡牌底纹，不改游戏原纹理尺寸，不替换牌名、图案、花色点数、选中与交互层。背面按原生 `IsEmpty` 判断；扑克模式、旧卡面与禁止刷新的状态保留原生行为。仅本机显示，不发送换装请求，不改变账号拥有的外观。此版本不替换技能特效里的卡背或不满足该结构的特殊卡牌。

停用、切换、对象移除与核心关闭时撤销实例包装；只恢复仍由核心持有的纹理，保留其他代码后写入的值。原生刷新产生的新纹理成为恢复目标。卸载时释放自有 GPU 纹理。

卡面和卡背独立选择，可限定仅自己或应用所有人。原生特殊卡图优先保留；对象复用与刷新时跟随当前选择，关闭或停用恢复原生显示。
