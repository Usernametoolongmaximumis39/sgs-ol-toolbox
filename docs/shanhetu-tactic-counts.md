# 战法计数（山河图 0.2.15 / 核心 0.5.82）

计数由山河图插件独立提供，不依赖卡牌插件，不以地图场景或模式名称为开关。只要战斗的自身座位提供共用 `zhanFaItems`，山河图、单骑无双及其他使用该原生战法控件的模式都会在相应图标右上角显示计数。纯只读，不更改战法的 Value、Activated、原生提示或点击操作。

| 战法 / PlotID | 显示与统计 |
| --- | --- |
| 神龙摆尾Ⅱ / 2143 | 摸牌张数模 6，显示 0/6 至 5/6 |
| 神龙摆尾 / 2104 | 摸牌张数模 9 |
| 三板斧 / 2042、2043、2044 | 使用【杀】张数模 3 |
| 手到擒来 / 2079、2080、2081 | 本回合使用牌的次数 |
| 多多益善 / 2082、2083、2084 | 本回合摸牌批次；一次摸多张只算一次 |
| 每轮触发 / 2033、2034、2035、2036、2037、2038、2048、2049、2050、2196、2197、2300、2301 | 原生战法触发通知次数，每轮重置 |
| 每回合触发 / 2100、2101、2108、2109、2110、2312、2313、2317、2319、2320、2321、2322 | 原生战法触发通知次数，每回合重置 |

总计 36 个战法 ID；未核实的战法不猜测。普通零值显示 0，周期起点显示 0/N；不完整历史显示 ? 或 ?/N。

摸牌仅计战斗开始后 `PubGsCMoveCard` 的 FromZone=1、ToZone=5、MoveType=1，排除初始发牌、转移和其他获得牌。`PubGsCUseCard` 与虚拟/转换牌消息 `MsgNtfUseCardType` 仅计 useType=1；三板斧按旧版的 SpellID=1。触发次数读取 `decodeRogueLikeItemEffectNtf.itemId/param[0]`，不把图标刷新或动画重播当成触发。所有计数按座位隔离，界面只展示自身。

每轮由 `MsgGameTurnNtf.TurnCnt` 重置轮次类战法，每回合由 `GsCGamephaseNtf.Round=0` 重置回合类战法。三板斧和神龙摆尾跨回合累计。新局、退出及切换账号清空；重连或消息缺口将历史标为未知，回合/轮次类可在下一次对应边界恢复，跨回合周期需等下一局完整开局。停用插件期间核心继续纯计算归约，重新启用不重计历史。

使用已观察的 `GsCRoleOptTargetNtf`、`Type=64`（官方 `OPT_ROGUE1V1_EX_SKILLS`），按原生结构 `[技能数, ...技能, 战法数, ...战法]` 解析完整战法列表。官方客户端据此设置对应 SeatID 的 `Rogue1v1Zhanfas` 并发出 `ZHANFA_CHANGE`。

神龙摆尾 2104/2143 各自从加入战法列表时开始独立累计摸牌，获得前的张数不计入；重复同步不会归零，移除后再次获得或加入新的等级 ID 从零起算。计数属于 reducer 状态，与图标对象、场景重建和插件重载无关，按座位隔离。其他战法按各自规则计数。

单骑无双未同步战法归属前显示未知；中途接入、重连及消息缺口之后的首个完整列表不假定已有战法刚获得，也不伪装成零。确认不存在后再观察到新增，可以建立新的可靠起点。无效或截断列表不被当成空列表。
