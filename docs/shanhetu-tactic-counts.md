# 山河图战法计数

启用山河图插件后，在支持的山河图、单骑无双等战斗中，可以从自己战法图标的右上角看计数。游戏里的战法说明及操作照常使用。

| 战法 | 右上角的数字 |
| --- | --- |
| 神龙摆尾Ⅱ | 获得该战法后每摸满 6 张牌重新起算，显示 0/6 到 5/6 |
| 神龙摆尾 | 获得该战法后每摸满 9 张牌重新起算，显示 0/9 到 8/9 |
| 三板斧、三板斧Ⅱ | 每使用满 3 张【杀】重新起算，显示 0/3 到 2/3 |
| 手到擒来、手到擒来Ⅱ、手到擒来Ⅲ | 本回合已使用牌的次数 |
| 多多益善、多多益善Ⅱ、多多益善Ⅲ | 本回合摸牌的次数，一次摸多张只算一次 |
| 双刃、双刃Ⅱ、当头一棒、当头一棒Ⅱ、淬血、淬血Ⅱ、淬血Ⅲ、厚实Ⅰ、厚实Ⅱ、削命、谋命 | 本轮已触发的次数，下轮重新起算 |
| 雷火势Ⅰ、雷火势Ⅱ、虎骨酒、虎骨酒Ⅱ、妙技 I、妙技 II、反刺、药理、药理 II、药理 III、药理 IV | 本回合已触发的次数，下回合重新起算 |

「0」或「0/6」等表示已经确认从零起算。「?」或「?/6」等表示记录不完整，例如重连、半途进入或战法归属尚未读到。按轮或回合统计的数字可在下一轮或下一回合恢复；跨回合累计的数字可能要等下一局或重新获得该战法。初始发牌和从他人处获得的牌不算摸牌。没有数字的战法可能尚未支持。
