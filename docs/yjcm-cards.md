# 一将成名卡面包 0.1.2

需要核心 **0.5.125**。独立插件 ID 为 `yjcm-cards`，无插件前置，包含「喵喵杯」「猪猪侠」两个完整卡面选项。入口：管理 → 设置 → 卡面与卡背 → 卡面。沿用卡面／卡背独立选择及仅自己／所有人范围；此插件不提供卡背，不改变已有选择。

美术来自三国杀官方资源服务器 `https://web.sanguosha.com/x/pc/res/assets/cards/normal/`。包名按用户要求命名；此处记录可核验的官方资源地址，不额外宣称资源的最初创作或迁移历史。美术版权归原权利人，工具箱不把这些图片标为原创。

| 套装 | 索引 | 图片 | 下载总字节 |
| --- | --- | --- | ---: |
| 喵喵杯 | `cardMiaoMiaoBei.atlas` | `cardMiaoMiaoBei.png` | 5,072,576 |
| 猪猪侠 | `cardZhuZhuXia.atlas` | `cardZhuZhuXia.png`、`cardZhuZhuXia1.png` | 5,419,160 |

每个文件的完整 URL、字节数和 SHA-256 均声明在 `src/plugins/yjcm-cards/resources.js`，随插件包一同校验。插件包包含注册代码与引用清单，内置两张从官方原图精确裁切的「杀」卡牌预览（每套一张），整套图集不内嵌。安装、启用和展开设置不下载整套资源，两张内嵌预览立即可见；选用时下载对应整套资源并逐文件校验，游戏中按需创建各张牌的纹理，普通出牌不重新下载。刷新后的网络传输取决于浏览器 HTTP 缓存；没有声称永久离线缓存。

不携带账号凭据，不上传牌局数据。核心限制索引 512 KiB、单图 8 MiB、图片边长 4096、图片页数 4，整次加载限时 20 秒。失败可在设置中查看完整状态并重试。切换、停用、卸载或核心关闭会取消加载、释放自有图片与纹理，迟到的异步结果不会重新应用。

1. 只对支持的普通新卡面 UI 生效。扑克及原生明确指定的特殊卡图优先保留游戏行为。异牌和技能变牌标签不单独拦截新卡面；技能选择及商店展示的虚拟牌按精确资源名匹配，花色点数仍由原生控制。
2. 按原生 `ResName` 精确查找 `ResName + '_png.png'`。国战、限时、活动牌有同名完整卡图时直接使用；不去掉后缀、不用显示名猜测、不把某张特殊牌映射成杀或其他普通牌，也不跨套装借图。
3. 索引没有同名图、切片越界、旋转或裁切布局不受支持时，完整保留该牌原生底纹、插画、牌名及说明；不会留下上一张复用卡的画面。
4. 下载失败、超时、资源哈希变化时整套完整卡面保持原生，卡背的独立选择不受影响。更新后的官方图片须经插件版本更新核验，不能静默接受新字节。
5. 完整卡图命中时仅隐藏重复的原生插画／牌名／类别说明层；花色、点数、交互与选中层仍由游戏控制。回退或停用时恢复这些原生层，不修改全局资源表或官方共享纹理。

移除异牌／技能标签对新卡面的过度排除，保留原实体的虚拟牌允许精确匹配。状态新增完整卡面实际替换数及回退原因，发现对象不再等同于替换成功。官方静态配置中截图五张牌的资源名均能在两套图集中精确匹配；不据此声称已复现该官服场景的全部运行字段。

完整卡图支持原生新卡面组合层和普通整张卡图两条路径，不再以 isNewCardUI 为 false 拦截普通手牌；整张卡图模式下的异牌专用图仍保留原生。纹理应用错误进入回退详情，不再被后续正常状态覆盖。加载成功后状态包含“完整卡面 R3 已替换 X/Y”，用于核对实际渲染代码。

完整卡图不再固定为 93×130。按照当前原生 UI 的宽高（尚未测量时读取原生纹理尺寸）创建对应逻辑尺寸的自有纹理；缓存键包含牌名与宽高，手牌和技能选择窗口不共享可变尺寸。不会修改官方共享纹理或卡牌缩放值。

官方 Laya Graphics.drawTexture 在创建命令时按 texture.width/sourceWidth 和 height/sourceHeight 缩放，原生 fO.updateSingleTexture 更新命令时直接写显示尺寸。自有纹理现在同步设置 width/sourceWidth 和 height/sourceHeight，避免新建命令与后续更新尺寸不一致。

仅包装已确认卡牌的 bmpFace 实例 texture accessor，识别已知原生普通纹理的直接刷新并在同次调用内重应用。原生 SetCardFace、布局、尺寸和 Draw 返回前刷新该实例已有渲染命令及重复图层，已加载图集不依赖 400ms 发现轮询完成换图。未知直接写入的特殊图、明确的技能覆盖保留原生；停止时只还原仍由核心持有的 accessor。临时隐藏的 tempHandCardUis 也纳入限定发现范围。

使用官方基础 card.atlas/card.png 对每张同名完整卡面解码后的 135×190 RGBA 像素逐字节比较，无视觉相似度阈值。两套各有 93 张完全相同，不替换：不生成自有 GPU 纹理、不隐藏原生图层，木牛流马和国战先驱等沿用游戏显示。喵喵杯替换 44 张（其中 ShanShan 无默认同名对照），猪猪侠替换 46 张（其中三张 ZZ 专属牌无默认同名对照）；无默认对照的主题专属图保留精确匹配能力，不猜测相等。

- 补齐原生 virtualCardUis、cardUIList 列表及商店控件独立 cardUi/cardUI 字段，避免已接管的非显示树子节点被下一次巡检误认为已移除。
- 虚拟标记本身不再排除完整卡图；同名差异图可精确匹配，默认相同图仍跳过，扑克、旧式异牌专用图和明确特殊覆盖仍保留原生。
- 已发现手牌容器的技能选择、虚拟牌展示和恢复方法前后同步检查其限定字段；已知场景、stage 及前两级显示层的 addChild/addChildAt 实例在插入返回前接管新窗口。没有修改全局原型，不把400ms巡检当作正常替换时机。
- 已知当前原生基础卡面纹理的直接刷新不会被错误判成特殊图；未知特殊图仍保留。
