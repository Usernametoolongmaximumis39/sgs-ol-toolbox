# 主题工坊与主题包

主题工坊是核心内置设置，从核心 `0.5.14` 起位于「管理 → 设置 → 主题工坊」。配色预览、选择、主题注册、持久化与加载生命周期均由核心提供，不需要安装加载器插件。即使没有安装主题包，Full 和 Lite 都提供默认玄金以及原雅色主题包的五套深色与三套浅色配色。

「流彩主题包」可从插件市场按需安装，提供八套渐变与暗纹主题。安装后在主题工坊选择；安装本身不会自动换主题。

| 主题 | 配色 |
|---|---|
| 玄金 | 核心默认，玄色与暖金 |
| 青瓷 | 墨绿与青玉 |
| 霁蓝 | 深蓝与天青 |
| 紫宸 | 烟紫与淡藤 |
| 朱砂 | 暗红与绯霞 |
| 霜银 | 冷灰与银白 |
| 宣纸 | 暖白纸色、墨字与茶金（浅色） |
| 晴岚 | 浅青蓝、远山青（浅色） |
| 桃夭 | 柔白胭脂、淡桃色（浅色） |

安装和启用主题包不会自动切换主题。选择即时生效并自动保存；停用或卸载正在使用的主题包会暂回玄金，但保留选择。重新启用或重装后恢复；期间手动选择其他主题会优先保留。

原雅色主题并入核心后，已选配色会保留。自定义主题包不受此合并影响。

直接使用核心 `ctx.themes.register({id, name, description?, tokens})`，无需依赖雅色主题包或实现主题加载器、选择面板。主题 ID 必须以自己的插件 ID 加点号开头，注册随插件 scope 自动撤销；核心设置实时发现注册或撤销的主题，不限制数量。未提供的 token 使用核心默认值。使用独立配色包时声明 `categories: []`，不要注册面板。

```js
export const manifest = {
  id: 'example.palette', name: '示例配色包', version: '0.1.0',
  apiVersion: 1, contractVersion: 1, minCoreVersion: '0.5.14',
  description: '向设置中的主题工坊添加一套配色。',
  icon: 'palette', priority: 32768, categories: [],
};
export default {
  manifest,
  activate(ctx) {
    ctx.themes.register({
      id: 'example.palette.night', name: '夜色', description: '沉静深蓝',
      tokens: { bg: '#161f2c', accent: '#91bcee' },
    });
  },
};
```

主面板、收起栏、公共控件、插件 HTML 与已接入主题接口的 Laya 控件实时跟随配色；保留游戏卡面、花色、品质标识等业务语义色。详见[插件 API](plugin-api.md)、[插件开发规范](plugin-development.md)和[原生主题说明](native-themes.md)。

## 浅色主题

浅色主题通过 `tokens.scheme: 'light'` 声明，默认仍是 `dark`；该字段只接受这两个值。核心同步浏览器表单／滚动条色系，原生面板使用较轻的阴影。回到深色主题后恢复默认深色色系，不修改用户业务配置或默认主题。三套浅色配色的正文、辅助文字、强调色和错误色在 bg/surface/raised 上的最低计算对比度分别为 5.30、5.21、5.18，均高于 4.5。

皮肤窗口本体保留游戏原来的背景；工具箱自有统计与静态／动态标签在浅色主题下增加自己的底层，避免深色文字直接叠在游戏深底上。卡面和稀有度等业务语义配色不改变。
