# 主题工坊与主题包

主题工坊是核心内置设置，从核心 `0.5.14` 起位于「管理 → 设置 → 主题工坊」。配色预览、选择、主题注册、持久化与加载生命周期均由核心提供，不需要安装加载器插件。即使没有任何主题包，工坊仍显示默认玄金。

随核心提供的 `themes` 插件为「雅色主题包」，版本 `0.1.3`，最低核心 `0.5.15`。它注册五套深色与三套浅色配色，声明 `categories: []`，不注册任何面板，不在牌局／自动／工具／信息等分类中列出。管理的插件市场仍可安装、停用、回退或卸载主题包。

| 主题 | 配色 |
|---|---|
| 玄金 | 核心默认，玄色与暖金 |
| 青瓷 | 墨绿与青玉 |
| 霁蓝 | 深蓝与天青 |
| 紫宸 | 烟紫与淡藤 |
| 朱砂 | 暗红与绯霞 |
| 霜银 | 冷灰与银白 |
| 宣纸 | 暖白纸色、墨字与茶金（浅色） |
| 晴岚 | 浅青蓝、远山青（浅色） |
| 桃夭 | 柔白胭脂、淡桃色（浅色） |

安装和启用主题包不会自动切换主题。选择即时生效并自动保存；停用或卸载正在使用的主题包会暂回玄金，但保留选择。重新启用或重装后恢复；期间手动选择其他主题会优先保留。

从旧版迁移保留 `themes.*` 主题 ID、原选择、停用和卸载状态；仅将已核实摘要的历史包更新为配色包，用户明确回退后不反复迁移。自定义包保持原样。旧版 `0.1.1` 工坊包的最低核心为 `0.5.0`，不代表当前新包的要求。

## 开发者接入

直接使用核心 `ctx.themes.register({id, name, description?, tokens})`，无需依赖雅色主题包或实现主题加载器、选择面板。主题 ID 必须以自己的插件 ID 加点号开头，注册随插件 scope 自动撤销；核心设置实时发现注册或撤销的主题，不限制数量。未提供的 token 使用核心默认值。使用独立配色包时声明 `categories: []`，不要注册面板。

```js
export const manifest = {
  id: 'example.palette', name: '示例配色包', version: '0.1.0',
  apiVersion: 1, contractVersion: 1, minCoreVersion: '0.5.14',
  description: '向设置中的主题工坊添加一套配色。',
  icon: 'palette', priority: 32768, categories: [],
};
export default {
  manifest,
  activate(ctx) {
    ctx.themes.register({
      id: 'example.palette.night', name: '夜色', description: '沉静深蓝',
      tokens: { bg: '#161f2c', accent: '#91bcee' },
    });
  },
};
```

主面板、收起栏、公共控件、插件 HTML 与已接入主题接口的 Laya 控件实时跟随配色；保留游戏卡面、花色、品质标识等业务语义色。详见[插件 API](plugin-api.md)、[插件开发规范](plugin-development.md)和[原生主题说明](native-themes.md)。

## 浅色主题（核心 0.5.15）

浅色主题通过 `tokens.scheme: 'light'` 声明，默认仍是 `dark`；该字段只接受这两个值。核心同步浏览器表单／滚动条色系，原生面板使用较轻的阴影。回到深色主题后恢复默认深色色系，不修改用户业务配置或默认主题。三套浅色配色的正文、辅助文字、强调色和错误色在 bg/surface/raised 上的最低计算对比度分别为 5.30、5.21、5.18，均高于 4.5。

皮肤窗口本体保留游戏原来的背景；工具箱自有统计与静态／动态标签在浅色主题下增加自己的底层，避免深色文字直接叠在游戏深底上。卡面和稀有度等业务语义配色不改变。

## 非纯色主题评估（方案，尚未实现）

结论：可以扩展，但应把“可读的基础配色”和“装饰背景”分开。现有 `tokens` 同时进入 CSS 颜色、`color-mix`、Laya 实体色与文字属性，不能把渐变、图片或动画字符串直接塞进 `bg` 并声称全界面支持。当前内部已经用线性／径向渐变绘制 HTML 按钮、悬浮栏与 Laya SVG 表面，这是控件样式，并不是任意主题素材加载接口。

| 类型 | 当前状态 | 建议接入方式 |
| --- | --- | --- |
| 自定义渐变 | 只有控件内置的渐变，没有主题级自定义渐变字段 | 核心增加结构化渐变装饰层，限定类型、角度和色标；原生控件保留基础配色，后续可按需转成缓存纹理。 |
| 指定人物形象 | 当前没有人物素材加载接口，token 会过滤 `url()` | 主题包携带静态素材，内核统一解码、裁切与展示；提供人物位置、可见区域和遮罩，文字区保持稳定底色。窄侧栏优先只在顶部／底部留人物局部。 |
| 动态主题 | 当前没有主题动画、视频或粒子加载接口 | 先做缓慢渐变／少量装饰位移；人物动态再考虑分帧图或短视频。动画单独开关，响应减少动画偏好；页面隐藏、面板折叠时暂停，切主题或卸载时释放。 |

建议下一阶段只增加内核维护的声明式 `decoration` 能力；它与 `tokens` 并列，具体格式尚未发布，不是当前可调用的 API。主题包仍声明空分类，仅提供配色与素材，不再实现加载器、不注入任意 CSS／动画脚本。优先支持随包内嵌素材；如以后增加外部素材，需单独定义来源、大小、超时、失败回退和截图行为，不因预览自动上传或访问第三方。

完整实现还需处理图片／视频加载失败、切换后的迟到回调、纹理和媒体释放、文字遮罩、透明度、HTML 与原生 Laya 的能力差异。首版可以只装饰核心 HTML 主面板，原生界面同步基础配色；如需人物出现在原生面板，再另做原生绘制适配。动态装饰不能拦截点击、改变布局或影响对局帧率；减少动画时展示静态首帧／静态渐变。
