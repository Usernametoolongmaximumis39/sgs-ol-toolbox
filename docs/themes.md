# 主题工坊与流彩主题包

打开工具箱「管理 → 外观 → 主题工坊」。点标题展开后，可以直接看每套配色的预览、名字和简介。点预览卡或卡上的「切换」应用配色，「使用中」标出当前主题，选择会自动保存。

## 自带配色

- 深色有青瓷、霁蓝、紫宸、朱砂、霜银，另有默认的「玄金」。
- 浅色有宣纸、晴岚、桃夭。

## 流彩主题包

Full 已随附「流彩主题包」，Lite 可在「管理 → 插件市场」安装并启用。启用后回到主题工坊即可看到五套深色和三套浅色渐变暗纹主题。应用时仍需点选想用的配色。点选方式与自带主题相同。

千里青绿、赤壁流霞、星汉极光、云锦织金、墨韵烟波、朝霞云绡、天青烟雨、金笺素绫。

停用提供当前配色的插件时，界面暂时回到玄金。再次启用可恢复之前的选择。如果期间主动切换了配色，则以新选择为准。主题改变工具箱和支持跟随它的控件外观。
