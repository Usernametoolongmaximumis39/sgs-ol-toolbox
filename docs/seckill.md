# 自动秒杀

在自动页选择商品或自定义关键词，再开启总开关。自动购买默认关闭，未设置时预选功勋和皮肤包，其余目标不选。开启后会购买商品并消耗对应游戏货币，必须核对商品、数量、价格和货币；自定义短词可能匹配多个商品。

商品身份、库存、限购或售卖状态未知时不购买；结果未确认时保留记录并核对，不以超时为由连续购买。关闭开关或停用可停止后续请求，已发出的请求无法撤回。折叠面板不停止购买。账号首次使用默认关闭，记录按账号保存在本机。

祈福灯目标为十个装、6666元宝；普通夺宝券不包含奇珍夺宝券。取消临时优先会暂停自动购买十分钟。请关闭其他脚本的购买任务，避免重复扣款；不承诺抢购成功或库存竞争结果，尚未完成真实扣款验收。
