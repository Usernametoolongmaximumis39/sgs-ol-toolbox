# 三国斗地主

在工具箱的「管理 → 插件市场」安装三国斗地主。登录经典版后，从游戏的「活动场 → 三国斗地主」打开大厅。

可在大厅用原生「开始匹配」按钮发起在线匹配，或在工具箱的「工具」末尾使用对应操作。

- **开始匹配**：经典版未开放时，按钮会在本次标签页会话首次使用时要求再次点击确认，然后尝试匹配。排队可取消，入座后可用同一个按钮准备。此功能仍在测试，仅用于小号；是否能入场由游戏服务器决定，参与对局可能消耗欢乐豆。
- **切换牌桌**在游戏已分配牌桌且座位信息齐全后可用。正常开局时游戏会自动进入牌桌。
- **复制日志**将本次大厅的匹配事件复制到剪贴板，便于反馈。日志不含账号、昵称或登录凭据，插件不会上传日志。

在经典版「战绩 → 历史战绩」中，可从「三国斗地主」分类播放对应录像。经典版的「播放本地录像」也可打开对应的重制版录像。

## 更新历史
