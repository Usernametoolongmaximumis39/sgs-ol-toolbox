# 三国斗地主

Full 已随附「三国斗地主」，Lite 可在工具箱「管理 → 插件市场」安装并启用。登录经典版后，从游戏「活动场 → 三国斗地主」打开大厅。工具箱「工具 → 三国斗地主」也提供大厅操作。

## 大厅

- 「开始匹配」发起在线匹配。首次会弹出「确认发起匹配」，确认后记住选择。排队开始后显示「取消匹配」，按钮至少约两秒内不可用，收到游戏的排队确认后才可取消。
- 匹配成功后大厅匹配按钮可能隐藏。工具箱出现「发送准备」时可点击准备，显示「等待开局」后等游戏开局。游戏正常开局会自动进桌，若已分配牌桌且座位齐全，也可点「切换牌桌」。
- 「复制日志」把本次大厅匹配的事件复制到剪贴板，便于反馈。日志省去账号、昵称和游戏登录凭据，插件不会代为上传。若浏览器拒绝访问剪贴板，请检查权限。

## 牌桌

- 点击一张手牌选中或取消，也可拖过多张牌批量选中或取消。选完需自己点出牌。支持的键盘操作可用方向键挑选手牌或选项，用回车或空格确认。
- 钟会发动「权计」时，上排是权计牌，下排是自己的手牌。各选一张再用游戏按钮确认交换。两排按点数从大到小排列，破军和权计区的暗牌仍保持隐藏。
- 断线后，只有游戏确认仍在同一对局时才尝试回到该牌桌。

## 战绩与录像

打开经典版「战绩 → 历史战绩」，切到「三国斗地主」，点对应对局的录像播放入口。已有录像文件时，可从游戏「播放本地录像」选择支持的官方录像，也可打开对应的重制版录像。播放结束或点返回可退出。在线对局或匹配期间先退出当前活动，再打开录像。

经典版未开放时，大厅可能允许确认后尝试匹配，适合用小号测试。能否放行、重连和扣除多少欢乐豆以游戏为准。部分技能移牌的公开或隐藏显示仍需核对。
