# 皮肤管理

打开工具箱「工具 → 皮肤管理」设置游戏皮肤窗口，也可给本局已亮出的武将临时换装。外服立绘、动皮和配音只在自己这边显示或播放。

## 游戏皮肤窗口

- 「高级皮肤整理」默认开启，打开游戏皮肤管理后可按「势力分类」或「品质分类」浏览。可切换新品、魏蜀吴群、普通至限定等标签，并用放大镜搜索武将或皮肤。「一键已读」清除该窗口的新品提示。
- 「制作」可选全部、可朱砂制作、不可朱砂制作。「已拥有」「未拥有」筛选收藏情况，点亮的选项再点一次可取消。
- 「动态」分四组。动态类型可选「无动态」「需解锁动态」「自带动态」，动态拥有可选「未拥有动态」「已有动态」，解锁方式可选「可朱砂升级」「仅水晶升级」，水晶准备可选「已有水晶」「缺少水晶」。同一组满足其中一项即可，不同组需要同时满足。点某组「不限」清除该组条件，点「重置」清除所有动态条件。
- 「快速下载原图」默认开启，在可读取的皮肤详情点「下载皮肤原图」保存官方静态图片。它需要联网，部分资源可能无法下载。
- 「一键牌局背景（需插件）」默认开启，需同时启用「自定义背景」。用「可作为牌局背景」筛选横版图，在详情点「作为牌局背景」选用。

## 本局临时换肤

- 「本地解锁皮肤」「本地解锁动态」默认关闭，可在游戏「选择皮肤」窗口试用未开通外观，或在支持的自用皮肤上播放动态。拥有情况仍以游戏为准。
- 「切换他人皮肤」允许从已亮出的其他武将中选择。「选择武将」「选择皮肤」选好后点「本地使用」，「恢复原皮肤」撤销这一武将的替换。也可用「导入外服图片」选择 PNG、JPEG 或 WebP 静态图。
- 「更换其他服务器皮肤」打开后可使用「一将成名皮肤」「移动版皮肤」入口。牌局中可给选中的武将换装，支持的武将详情也可提前选皮肤，按「下次使用」保存给下次上场。
- 「皮肤显示优化」默认开启，会在支持的己方立绘展示时自动收起武将名条和聊天输入行。也可用牌桌上的收起控件手动切换，恢复时再点一次。按钮获得焦点后可用回车或空格操作。

## 一将成名和移动版选择器

- 用「搜索所属武将」或所属武将标签筛选，点「显示更多」继续查看。点皮肤看预览，支持多形态时可切换形态；支持官方演示时可点「播放官方演示」。列表加载失败可点「重试加载」。
- 「选立绘」与「选配音」用来分别挑选素材。「使用皮肤」应用本局选择。出现「继续未完成配置」时，可回到上次的配置。
- 点配音选项试听，有多条时可继续点按。选中外服技能配音，再点目标武将技能可绑定或取消。可用时「一键绑定」优先匹配同名技能。「未识别配音」「卡牌配音」可展开试听，支持时可开「替换同名卡牌配音」和「替换 MVP 语音」。也可选择保留 OL 原配音或使用随机配音。
- 「皮肤动效」可选预览项目并播放，支持时可指定登场或技能特效。动效读取失败时可重试，播放失败可展开详情。
- 多形态皮肤可点「形态规则」选择「默认规则」或「原皮规则」可随内置规则切换，「仅手动」只用牌桌上的形态按钮。「自定义」可选起始与目标形态，点「添加规则」，最多添加六条。可按体力、发动技能的次数、任一或全部指定技能、转换技阴阳变化等条件触发，按选项填写体力值、次数或技能。可逐条启停或移除，点「确认规则」保存。技能目录失败可重试。牌桌上出现「形态」时可直接选择支持的形态。
- 支持的横版皮肤可点「设为牌局背景」。点窗口的关闭按钮可返回游戏。

图像、动皮、配音和特效按需联网加载，实际可用范围随皮肤、来源和设备而异。下载或本地试用不会取得皮肤所有权或素材授权。
