# 皮肤管理

在游戏皮肤界面筛选和查找皮肤，查看收藏与动态状态；皮肤详情支持下载可读取的官方静态原画。关闭详情后下载按钮随之隐藏。下载需要联网，可能受资源地址和跨域限制影响；不支持下载动态资源，也不提供皮肤所有权或授权。

对本局已亮出的武将可临时切换本地立绘或导入 PNG、JPEG 和 WebP 图片。本地外观仅自己可见，停用后恢复游戏显示。

在本局切换外服皮肤时，可从一将成名服或移动版目录选择。图片、动皮、配音和特效会按需联网加载，能使用的效果随皮肤和设备而异。外服皮肤仅在自己这边显示或播放。

## 开发历史

- 0.4.109：减少未打开皮肤窗口时的后台检查，不改变皮肤选择和已有设置。
- 0.4.107（2026-11-22）：改进本地多形态皮肤对转换技阴阳状态切换的识别。

- 0.4.87（2026-11-20）新增移动版皮肤入口，可按需联网加载静态原画、动皮、语音和部分特效。支持手动切换可用的多形态皮肤，以及选择支持的登场、技能特效和胜利配音。调整局内动皮和头像布局，修复势周瑜水火形态共用原画的显示问题。外服及导入皮肤只在自己这边显示或播放。资源加载和演出受来源及设备支持限制。

- 0.4.56（2026-11-19） 可为本局武将选择一将成名服皮肤，并按需联网加载立绘、配音与部分动皮演出。皮肤与配音仅本机可见或可听。支持切换已应用皮肤的形态、收起本方武将名条及聊天输入行，亦可在一将成名动皮播放时自动收起。首次打开外服皮肤列表需要联网建立索引。

- 皮肤管理 0.4.13（2026-11-19）：新增皮肤管理整理开关、详情页下载和背景快捷操作。可为本局已亮出的武将临时切换立绘或导入静态图片，效果仅在本机显示。


- 0.4.9（2026-11-16）：精简皮肤原画下载按钮的样式加载，原有筛选和静态原画下载方式保持不变。
