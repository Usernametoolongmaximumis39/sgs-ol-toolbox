# 玩家信息

显示玩家资料、官阶及客户端可提供的地主和农民胜率；缺失数据显示未知。选将时资料卡位于上层，与卡牌或选将窗口相交的局部区域半透明，未重叠部分保持原样，结束选将后恢复。数据依赖游戏当前提供的信息，不保证每个模式均可读取。

玩家资料卡和检查将灯默认开启，已有关闭选择会保留；可在设置中关闭或调整关注武将。检查会查询游戏服务器，并按需加载武将原画；临时拥有状态可能影响结果，查询失败时不把未知当成未拥有。

- 玩家信息 0.4.20（2026-11-19）：适配新版工具箱界面资源。玩家资料和将灯查询的用法沿用现有设置。

- 0.3.8（2026-11-16）：优化玩家资料卡的选将显示：与选将卡牌重叠的局部区域半透明，其他部分保持清晰；选将结束后恢复。
