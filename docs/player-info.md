# 资料与将池

对局里查看玩家资料和斗地主将灯，在大厅查找武将、保存和替换禁将方案。设置位于工具箱「牌局 → 资料与将池」。

## 玩家资料和将灯

- 「玩家资料卡」默认开启，显示游戏提供的玩家资料、官阶及可读取的地主、农民胜率。点收起控件可缩成头像旁的小圆点，点圆点展开。选将时重叠的区域会变淡，便于查看候选牌。查不到的资料显示为未知。
- 「检查将灯」默认开启，需同时打开资料卡。进入斗地主后自动向游戏查询在场玩家，地主确定后显示关注武将的拥有情况。查不到时保持未知，未点亮的武将也可能因体验卡或限免而可用。
- 「默认方案」使用内置关注名单。「自定义方案」可分别替换地主、农民各十个位置。点要替换的名字，搜索武将名称或带前缀的名字，再点候选完成替换。候选只来自当前斗地主将池，排除限时变体，同一位置组不会重复添加同一武将。

## 大厅将池与方案

- 「拓展将池」默认开启。在游戏将池窗口点「拓展将池」打开方案面板，输入「搜索武将」可筛选当前列表。开放及拥有情况以游戏结果为准。
- 「保存方案」先选游戏方案，再选「新建拓展方案」并输入名称，或选择已有拓展方案。点「保存新方案」创建。覆盖已有选项时点「核对并更新」，看过禁将差异后点「确认更新方案」。
- 「载入游戏」先选拓展方案，再选游戏目标方案，点「核对并载入」。核对新增禁将和解除禁将后，点「确认载入游戏」才会写入。使用该目标方案的游戏模式也会随之更新。
- 「管理方案」选中本地方案后，可输入新名称并点「保存名称」，或用「删除拓展方案… → 确认删除」删除。最多保存 20 份拓展方案。
- 「刷新」重新读取方案，「收起」关闭拓展面板。核对页可用「返回选择」改选，名单相同且显示「完成」时可直接退出核对。

将灯涉及游戏联网查询和官方原画加载。拓展方案按账号保存在本机，绑定云同步后会随支持的设置同步到绑定服务器。确认载入游戏才会修改游戏方案。
