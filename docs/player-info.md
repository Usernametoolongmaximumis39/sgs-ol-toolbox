# 玩家信息

独立插件 `player-info`，无前置、无设置、无持久化与上传。启用后在个人页和牌局玩家侧边显示可取得的昵称、官阶与战绩资料；排除本人，资料隐藏或缺失时如实提示，不推算胜率。

账号 ID 大于 4000000000 时显示人机提示。这是账号范围启发式，不能保证官方后续账号分配仍满足规则；缺失或非法 ID 不判断，不根据昵称猜测。个人页提示显示5秒，关闭重开可再次提示；牌局提示可关闭。

资料卡采用透明底板，官阶文字按当前官阶配色，长昵称可查看完整内容。自选身份演武资料按游戏可取得的数据展示。斗地主胜率的地主／农民合计口径尚未确认，不宣称已完成此项验证。

停用释放轮询、主题订阅、资料卡与提示。真实牌局布局及各模式战绩字段仍需官服复核。
