# 心愿进度 0.1.0

独立后台插件，不在工具箱 HUD 注册面板。启用后打开游戏心愿武将或心愿皮肤窗口即可查看。

- 武将：服务端 ratio × SplitNum / 10000，显示三位小数格数。
- 皮肤：ratio / 100，显示两位小数百分比。
- 最近一次成功单抽或五连同时收到结果与进度回包后显示净变化，兼容两种回包顺序；武将三位小数，皮肤三位小数百分比点，支持负值。
- 关闭、切页、更换心愿或账号后清空本次变化；数据未知不伪造为零。仅使用当前窗口内存，不保存账号进度，不发送抽奖、查询或外部请求。
- 移植来源：本机小抄的拓展 2.6.8 的自包含心愿模块。通过核心接口定位现有 ServerProxy 及已打开窗口，仅包装确认实例；停用后释放监听与包装并还原标签。
