# Full 与 Lite 发行版

Full 与 Lite 具有相同核心能力，使用同一脚本名称和身份；安装另一版时替换原脚本，不同时启用多个工具箱实例。

| 规则 | Full | Lite |
| --- | --- | --- |
| 随附内容 | 完整核心和选定的官方插件 | 完整核心，不随附插件 |
| 已安装插件 | 保留用户已有插件、配置与选择 | 同左 |
| 更新 | 扩展自动更新保持当前发行版；工具箱内更新使用 Lite | 同左 |
| 插件管理 | 独立安装、更新、停用、回退与卸载 | 同左 |

Full 的目标是固定携带少量最通用的官方插件。名单稍后确定，固定后不轻易修改；只有新增非常实用且通用的功能等充分理由才单独评估。新增官方插件不自动随附，社区插件在任何审核状态下均不随附。新白名单机制尚待完成，现有包的内容以实际发行包为准。

随附插件转存成功后切换 Lite，仍可继续使用。切换或更新不得清空配置、重新启用停用插件、撤销卸载选择或丢弃可回退包；转存失败须显示错误。核心与插件分别维护版本，核心更新不等于升级所有插件。

数据按浏览器站点保存，不代表跨浏览器或跨设备同步。清除站点数据会影响这些记录。插件的新增与修改遵守[开发规范](plugin-development.md)；社区来源与审核规则见[社区插件政策](community-plugin-policy.md)。
