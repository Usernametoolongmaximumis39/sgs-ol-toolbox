适用于已核实的官方 Windows 1.1.6 与 4399 渠道 1.1.3 微端。无需安装篡改猴，也不依赖旧小抄微端插件。

1. 建议先删除包括旧小抄在内的未知脚本并恢复官方微端；仅关闭或隐藏旧脚本不满足正常安装要求。
2. 完全退出微端（包括托盘），把本 ZIP 解压到微端目录之外。
3. 右键点击 install.bat，选择“以管理员身份运行”。
   安装器先查默认目录；找不到唯一目录时会检查当前所在目录（客户端根目录或 resources），
   仍找不到会提示输入安装路径。路径可带或不带 resources，支持官服和 4399。
   非默认位置：install.bat "D:\SGSOL" 或 install.bat "D:\SGSOL\resources"
4. 安装器先检查官方文件、旧脚本和已安装工具箱的完整性；检查通过后直接安装，无需输入确认。
   检查未通过时不会显示具体差异，而是提示你可能以前使用过小抄或其他辅助脚本，
   安装可能导致这些脚本丢失；确认风险后输入 y 继续，其他输入均取消。
   强制安装会跳过哈希与文件校验，旧的 app 目录将在成功后删除。
5. 看到“安装成功”后重新打开微端。

Lite：完整核心，不随附插件。Full：同一核心，随附当前选定的官方插件。
两个版本相互替换，设置、已装插件、停用、卸载与回退状态保留；不会清除微端用户数据。
插件安装、更新、回退和管理与浏览器版一致，使用 GitHub 主市场、OSS 备用市场。
浏览器和微端的配置文件独立，不会自动跨环境同步数据。

切换游戏渠道：客户端底部右侧的“渠道”按钮，或游戏目录下的 switch-channel.bat。
切换只保存本机渠道配置，不替换客户端文件或安装包；重启微端后生效。
按钮在工具箱 UI 外部，登录前也可用；切错服务器或脚本异常时可用 switch-channel.bat 改回。
两个渠道共用微端用户数据、登录状态和缓存，切换后可能需要退出账号重新登录。
旧版接入层没有此入口，需要重新运行安装包升级一次。

更新：在“插件市场”的“工具箱核心”中点击“检查脚本更新”，发现新版后点击“更新脚本”。
脚本保存到微端用户目录，下次打开游戏生效，无需重新安装或管理员权限，不打断当前牌局。
下载或校验失败会保留原脚本；更新后可在同一入口“回退脚本”。
更新检测超时修复需要退出微端并用新版安装包重新运行 install.bat 一次。
旧版接入层首次启用此功能需升级一次；今后的脚本更新不再运行 BAT。
核心更新不会自动升级全部已装插件。不要把 .user.js 当作微端安装包。
恢复官方微端：完全退出后，右键点击 restore.bat，选择“以管理员身份运行”（非默认位置同样传 resources 参数）。
恢复操作保留微端用户数据，不会代为删除未知脚本。

安装器离线运行，不下载或执行旧小抄；不会上传账号信息。
遇到未知 app/app.asar、旧小抄目录、脚本文件、安装器残留或校验失败时，默认中止并显示具体路径。
检查失败后可按提示输入 y 承担风险继续；resources 中 app 以外的未知脚本不会被代为删除，
外部注入器也不能被安装器检查或关闭。不要通过改名或编辑清单绕过检查。
外部注入器和目录外脚本只能由用户自行清理；扫描通过不能证明系统中不存在其他注入程序。
4399 渠道 1.1.3 已通过文件校验与安装／卸载验证；游戏内功能仍需在实际客户端确认。
官方更新或重装可能覆盖工具箱。请重新下载适配的工具箱安装包，不跟随旧小抄更新器。
当前不提供 macOS 安装器。
