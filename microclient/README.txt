三国杀 OL 工具箱 Windows 微端

支持已核实的官方 Windows 1.1.6 和 4399 渠道 1.1.3。
4399 的游戏内功能以实际客户端中的结果为准。安装器离线运行，不上传账号信息。

安装
1. 建议先恢复官方微端，并清理旧小抄或其他辅助脚本。
2. 完全退出微端（包括托盘），将压缩包解压至游戏目录之外。
3. 右键 install.bat，选择“以管理员身份运行”。在菜单输入 1 安装或更新，输入 0 退出。
4. 安装器先查默认目录，再检查当前所在位置。找不到时按提示输入游戏根目录或其中的 resources。
   非默认位置也可运行 install.bat "D:\SGSOL" 或 install.bat "D:\SGSOL\resources"。
5. 校验通过后直接安装。校验失败时会提示可能安装过旧小抄或其他辅助脚本。
   继续安装可能导致被替换的脚本丢失。只有输入 y 才会强制安装，其他输入均取消。
   强制安装成功后会删除被替换的 app 目录。看到“安装成功”后重新打开微端。

版本与更新
Lite 包含完整核心。Full 另随附选定的官方插件。
切换版本时运行相应安装包，保留已安装插件、设置以及停用、卸载和回退状态。
窗口顶部“核心”可分别检查、更新或回退核心脚本和微端底层。
启动时自动更新可以关闭，下载的更新重启后生效。下载或校验失败会保留当前版本。
新版底层连续启动异常会尝试自动回退。旧安装需运行新版安装包以获得顶部入口。
插件各自更新。浏览器脚本应使用浏览器脚本扩展安装。

切换渠道
点击微端右下角“渠道”，或运行游戏目录下的 switch-channel.bat，选择后重启。
此入口在工具箱外，登录前也可用。两个渠道共用微端用户数据、登录状态和缓存。
切换后可能要退出账号并重新登录。旧安装可能需更新后才有此入口。

恢复
完全退出微端，以管理员身份运行 restore.bat。非默认位置也可传入安装路径。也可在 install.bat 菜单输入 2 卸载并恢复。
恢复保留工具箱设置和插件数据。
校验通过后直接恢复。校验失败默认中止，只有输入 y 才强制恢复。
优先从官方备份恢复 app.asar，成功后删除被替换的 app 目录。
其中自行添加的脚本可能丢失。resources 中其他未知脚本及外部注入程序仍需自行清理。
更新或重装官方微端可能覆盖工具箱，此时请使用与官方版本适配的安装包。

数据与风险
微端与浏览器分别保存配置和记录，支持的记录可通过绑定云同步恢复。
清除微端用户数据可能丢失配置。当前插件没有真正的安全沙箱。
自动操作可能影响游戏账号，或消耗元宝、欢乐豆、其他游戏货币或道具。
插件说明与下载入口请见项目主页 https://tools.3gs.xyz/ 。
