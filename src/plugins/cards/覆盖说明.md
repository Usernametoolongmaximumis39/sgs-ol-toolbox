# 卡牌

打开工具箱「牌局 → 卡牌」，查看当前牌局的用牌、牌堆和他人曾公开过的牌。面板可收起，牌桌上另有快捷查看和理牌按钮。

## 牌桌快捷查看

- 点「玩家用牌／回合用牌」切换自己与当前回合玩家的最近用牌。
- 悬停看「牌堆顶」「牌堆底」「弃牌」，点一下固定，再点收起。按住数字键 1、2、3 可临时查看，放开关闭。按住 4、5、6 可分别按花色、类型、点数临时查看弃牌。
- 弃牌列表内点「时间」「花色」「类型」「点数」改变排序。滚动浏览，点「更多」继续显示余下的牌。
- 扩展理牌可点「类型」「花色」「点数」，双击排序按钮可锁定该排序，再双击取消。可拖动按钮组到顺手的位置。组间按钮在「组间留空」和「不留空」间切换。

## 牌堆、手牌与筛选

- 「牌堆结构」按「牌名」「花色」「点数」分组。点击类别名称查看该组的牌，点图钉关注该类别。收起工具箱后可查看置顶类别未见张数，置顶只在本局有效。
- 「手牌推断」点玩家条目展开，分开展示确定和可能在手里的牌。虚线与「可能」表示位置尚不能确定。
- 「卡牌组合查询」可同时按牌名、花色、点数和牌区筛选。牌区可选牌堆、弃牌、手牌、装备、判定、武将牌、临时区。选「全部」取消对应条件。结果太多时缩小筛选范围。
- 「记录状态」展开后可看本局是否缺少开局或部分过程。没有可靠信息时保留未知；无法查看从未公开的手牌。

## 显示与操作设置

| 项目 | 作用 |
| --- | --- |
| 最近用牌、牌堆顶底、本回合弃牌 | 分别控制快捷栏的这三类内容 |
| 他人明牌 | 在玩家旁标出已公开的手牌 |
| 不透明度、明牌每行 | 明牌不透明度可选 60%、80%、100%，每行可选 4 到 8 张 |
| 来源标签 | 在支持的牌上标出已知来历 |
| 四色花色 | 改用四种颜色区分花色，默认关闭 |
| 扩展理牌 | 显示额外的手牌排序按钮 |
| 出牌读秒 | 显示可读到的出牌或响应剩余时间 |
| 显示技能次数 | 显示已知技能剩余次数，包括零次及不限次数 |
| 技能提示 | 显示支持的牌局技能提示 |

### 山河图自动打牌

牌桌出现「自动打牌」时，单击开启或取消，右键可记住选择。开启后会代做支持的出牌和结束操作，请按需要随时取消。超出可处理的情况要自己操作。
