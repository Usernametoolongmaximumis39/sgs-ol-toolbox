# 卡牌插件 0.1.38：实现与验证边界

本插件独立运行，不加载原版小抄，不依赖原版随机全局名。仅使用客户端已收到的消息与原生公开牌信息；不请求其他玩家的隐藏手牌。

参考基线为官方小抄 1.6.76，SHA256：

`D59D7D8C4C9CE8B4FE10D45BE0EDCA652E82B5BEA101861E9665785B36A115D6`

调查时仅静态解析其包装字符串、索引表及条件分支，没有执行原版运行时。该版本的主要运行时字符串长度为 1,975,194 字符，索引表 6,704 项。本文件描述本次实现，不声称完整复刻原版所有技能推断。

## 0.2.23 / 卡牌0.1.38：展开详情自动可见 — 2026-11-14

- 点击牌堆类别展开时，自动将详情滚入可见区域，列表最后一项无需再手动向下滚动。
- 只在主动展开时调整滚动；消息刷新保留当前滚动位置，避免干扰阅读。
- 浏览器验证最后一类详情完整可见及消息刷新后保持手动位置，无页面错误。卡牌插件可热更新至0.1.38；完整安装包为核心0.2.23。

## 0.1.32 旁观读秒与双将明牌位置

- 卡牌0.1.32删除读秒的HTML定位兜底，只在连到当前Laya.stage、可见且原生countTween仍有效的计时条内显示数字。原生Stop不清除RemainValue，现不会把这一缓存当成正在读秒；未挂载、零尺寸、透明及已停止计时器不显示，已显示的插件文字会清理。
- 修正旁观双将头像的明牌定位：Kjt.ShowType使用scrollRect.x=36裁剪头像，而Laya.localToGlobal会减掉该偏移。现在转换可见裁剪矩形的左下角，兼容裁剪高度，不再落在头像左侧；未显示或空裁剪头像不生成标记。
- 正常活动计时条、选牌弹窗读秒和单将明牌继续保留；不按旁观身份一概关闭功能。

## 0.1.30 类别关注与弹窗读秒

- 卡牌0.1.30将牌堆表改为“未见/开局”，如2/3表示开局3张、已见1张；不再展示下限区间。首次实际收到牌号才标已见，开局全牌表和隐藏摸牌不算；同一张重复出现、回堆或洗牌不重复计数。旧记录缺少已见标记时显示不完整提示。
- 点击类别展开全部牌，区分已见/未见；星标临时置顶，切换面板保留，但新牌局、刷新/重载清空，不写入设置。杀汇总所有普通和属性杀，另列普通/火/雷/冰、红杀和黑杀交叉分组。
- 核心0.2.17提供实体牌类别元数据，解决牌名同为“杀”时的属性识别。选牌等原生窗口的计时条加入原生数字读秒；隐藏、关闭、停用时清理，不更改计时器。

- 新增八人乱序、UI 编号与模型冲突、动态换位、缺失身份及多人队友可见回归。模拟席位从1号位逆时针递增，覆盖本人分别在1至8号位；浏览器确认郝普（协议座位 3，即4号位）和陈宫（协议座位 6，即7号位）的各四张小牌位于对应模拟角色下方，排除本人，牌名未裁切；这不代表用户截图中的实局已现场复测。

## 0.1.2 实局空白修复

- 卡牌协议兼容 `Protocol`、`ProtoObj`、`Data`、`msg` 包装及客户端大小写字段；空的外层数组不会遮住内层非空牌号。支持数组、类型数组和有长度的牌号集合。核心另修复原生事件采集和 getter 字段复制，卡牌插件不再依赖只含自有属性的模拟消息。
- 明牌兼容公开的同手牌区移牌，以及好友手牌响应 `Protocol.error_id/seat_id/card_list`；失败响应及发送请求不记作明牌。
- 新增“牌堆结构”：开局牌表、当前剩余、弃牌总数，按牌名/花色/点数汇总。隐藏摸牌用剩余数量范围表达；不把可能仍在牌堆的牌标为确定。数量和位置冲突时，剩余总数显示未知。
- 中途启动而未收到开局牌表时，明确显示“尚未收到本局开局牌表”；后续收到的用牌和明牌仍能记录，但无法追溯安装前的消息。

包装形式另依据公开 95chong 1.0.51 源码 `https://xc.95chong.cn/downloads/sgs-xc.user.js` 中的协议事件转换核实。这里只静态检查其字段和调用方式，没有运行第三方脚本。

## 已实现的卡牌功能

| 功能 | 行为 | 自动验证 |
|---|---|---|
| 最近用牌 | 本人与当前回合角色切换 | 纯事件回放、界面挂载 |
| 牌堆结构 | 开局数量、剩余范围、弃牌总数；牌名/花色/点数汇总 | 隐藏摸牌上下限、再公开收窄、重连未知、缺失牌表 |
| 牌堆顶底 | 有证据的顺序；按住 1/2 临时查看，点击固定查看 | 顶底放回、未知摸牌、无序插入失效 |
| 本回合弃牌 | 时间、花色、类型、点数排序；按住 3–6 查看 | 跨回合清理、重复获得移除、洗牌 |
| 他人明牌 | 按真实 seatId 归属；原生座位下方与主面板均可查看 | 1–8 座、公开信息恢复、DOM 定位 |
| 未知归属展示区 | 0.1.34已删除；内部位置不确定性继续用于查询与合格推断 | 不显示独立列表 |
| 来源标签 | 摸牌、弃牌获得、来自其他席位等；在原生手牌上叠加标签 | 来源 reducer；叠层生命周期 |
| 四色花色 | 红桃红、黑桃原色、方块蓝、梅花绿，可关闭 | 设置与卡片渲染 |
| 卡牌组合查询 | 默认收起并记住选择；牌名/花色/点数/牌区下拉组合筛选，星标与常用牌优先 | 复合筛选、焦点和选择保留、关闭时不生成卡片 |
| 手牌整理 | 类型/花色/点数；双击锁定、长按拖动；选牌弹窗跟随手牌顺序 | 原生对象排序、选中状态保持、锁定、禁用及卸载恢复 |
| 出牌读秒 | 读取原生 RemainValue，不启动独立倒计时 | 原生剩余时间渲染、卸载清理 |

所有监听、定时器、UI 与方法补丁归插件 scope 管理。停用时还原原生理牌按钮、删除计时及卡牌叠层；核心继续收集本局事件，重载从核心现有状态恢复。本插件本身不发送游戏操作或聊天消息。

## 模式入口与特殊分支矩阵

不按模式 ID 设置白名单，未专门识别的模式使用相同的公开移牌/牌区规则。以下为 1.6.76 的卡牌相关模式分支。自动回放覆盖的是合成协议样例，不等于真实模式实测。

| 原版分支 | 新实现 | 已验证 | 尚需实局验证 |
